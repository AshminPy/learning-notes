What is machine learning?

You've learned Python, and you've learned the math behind ML (vectors, matrices, probability, statistics). Now it's time to answer the big question: what actually is machine learning? This lesson is conceptual — no code today. Coding starts again next lesson.

The core idea

A normal computer program follows hardcoded rules that a human wrote. Machine learning flips that: instead of a human writing the rules, a program learns patterns from data on its own.

Simple example: to detect spam email the old way, a programmer writes rules by hand: "if the email contains the word FREE in all caps, mark as spam." A machine learning model instead looks at thousands of emails already labeled "spam" or "not spam," and figures out the patterns itself — without anyone writing "if word = X" rules.

Google's Machine Learning Crash Course defines it this way: "ML is the process of training a piece of software, called a model, to make useful predictions or generate content ... from data." The model learns from examples instead of following instructions a human typed in.

The three main categories

Almost every ML system falls into one of three categories, based on what kind of data it learns from and how it learns.

1. Supervised learning — learning from labeled examples

The model is shown data where the "correct answer" is already attached (this is called a label). It learns the pattern that connects the input to the correct answer, so it can predict the answer for new, unseen data.

Supervised learning splits into two types:

TypePredictsExample
RegressionA numberPredicting a house's price from its square footage
ClassificationA categoryDeciding if an email is "spam" or "not spam"

Real-world example: a bank's fraud-detection system is trained on millions of past transactions, each labeled "fraud" or "not fraud." It learns to classify new transactions the same way.

2. Unsupervised learning — finding structure with no labels

The model is given data with no correct answers attached. Nobody tells it what the groups or patterns should be — it has to find structure on its own. A common task here is clustering: grouping similar items together.

Real-world example: an online store groups its customers into segments based on purchase behavior — "bargain hunters," "frequent big spenders," and so on — without anyone predefining what those groups should look like. The model discovers the groups from the data.

3. Reinforcement learning — learning by trial and error

Here there's no fixed dataset of labeled examples at all. An agent takes actions in an environment, and gets a reward (or penalty) depending on how good the action was. Over many attempts, it learns which actions lead to the best rewards.

Real-world example: a program learning to play chess plays millions of games against itself, getting a reward for winning and a penalty for losing, gradually learning better strategies — no human ever labels "this move is correct."

Try it — classify these scenarios

For each scenario below, decide: supervised (regression), supervised (classification), unsupervised, or reinforcement learning?

Q1. Grouping customers by purchase behavior, with no predefined groups.

Unsupervised learning — no labels exist telling the model what the groups are. It finds the structure (clusters) itself.

Q2. Predicting a house's price from its square footage, using past sale prices.

Supervised learning — regression — the model learns from labeled examples (past houses with known prices) and predicts a number.

Q3. Sorting photos into "cat" or "dog," trained on thousands of photos already tagged with the correct animal.

Supervised learning — classification — the labels are categories ("cat"/"dog"), not numbers, and the model learns from tagged examples.

Q4. A robot learning to walk by trying different movements and getting a higher score the further it walks without falling.

Reinforcement learning — there's no labeled dataset. The robot (the agent) learns from trial and error, guided by a reward signal (distance walked).

Recap
  • Machine learning: a program that learns patterns from data, instead of following hardcoded rules.
  • Supervised learning learns from labeled examples — regression predicts numbers, classification predicts categories.
  • Unsupervised learning finds structure (like clusters) in data that has no labels.
  • Reinforcement learning has an agent learn by trial and error, guided by rewards.
