Control flow: if/else and loops

So far your code runs top to bottom, one line after another. Control flow lets code make decisions and repeat itself. A model's training code is full of this: loops that go through thousands of training examples, one at a time, and conditionals that decide what to do with each one. This lesson covers both.

Simple example: think of a loop like checking every item in a laundry basket one at a time. For each item (a loop), you decide: is it dirty or clean? (a conditional). You repeat the check until the basket is empty.

if / elif / else — making decisions

Python checks a condition using comparison operators: == (equal), != (not equal), <, >, <=, >=. Note == checks equality; a single = assigns a value — mixing them up is a very common bug.

x = 0

if x < 0:
    print("Negative")
elif x == 0:
    print("Zero")
else:
    print("Positive")

There can be zero or more elif parts, and the final else is optional. Python checks each condition top to bottom and runs the first block that matches.

You can combine conditions with boolean operators: and (both must be true), or (at least one must be true), not (flips true/false).

age = 25
has_id = True

if age >= 18 and has_id:
    print("Allowed in")

if not has_id:
    print("Need ID")

for loops — repeat a fixed number of times, or over a list

A for loop goes through the items of a sequence (a list, a string, or a range of numbers) one at a time. range(5) generates the numbers 0, 1, 2, 3, 4 — it stops before the number you give it.

for i in range(5):
    print(i)
# prints 0, 1, 2, 3, 4

You can also loop directly over a list — each pass, the loop variable becomes the next item:

fruits = ["apple", "banana", "mango"]

for fruit in fruits:
    print(fruit)

Common trap: range(1, 11) gives you 1 through 10, not 1 through 11 — the second number is where the range stops, and it's excluded.

while loops — repeat until a condition is false

A while loop keeps running as long as its condition stays true. You are responsible for changing something inside the loop, or it never stops (an "infinite loop").

count = 0

while count < 3:
    print(count)
    count = count + 1
# prints 0, 1, 2

break and continue

Inside any loop, break stops the loop immediately. continue skips the rest of the current pass and jumps to the next one.

for num in range(2, 10):
    if num % 2 == 0:
        continue   # skip even numbers
    print(num)     # only odd numbers print

Try it — before looking below

Q1. What does range(1, 5) produce?

1, 2, 3, 4 — it starts at 1 and stops before 5.

Q2. Inside a loop, what is the difference between break and continue?

break stops the whole loop right away. continue only skips the rest of the current pass and moves on to the next one — the loop keeps going.

Recap
  • if / elif / else makes decisions, using comparisons (==, !=, <, >) and booleans (and, or, not).
  • for loops repeat over a list or a range() of numbers; while loops repeat until a condition turns false.
  • break exits a loop early; continue skips to the next pass.
  • Real model code is mostly this: loops over training data, conditionals deciding what to do with each example.
