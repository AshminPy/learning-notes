Tools setup: Python, notebooks, Git & GitHub

Three things, once, before any code: a place to run Python, a way to save code online, and a place to show it off. Do all three now — every later lesson assumes they exist.

1. Run Python — two options

Simple example: Python is just a program that reads your instructions and does them, one line at a time — like a very literal assistant.

OptionBest forHow
Google ColabStarting today, zero install, works in a browserGo to colab.research.google.com, sign in with any Google account, click "New notebook"
Local Python + JupyterOnce you're comfortable, for offline workInstall from python.org, then run pip install jupyter in a terminal

Start with Colab. It removes "did I install this correctly" as a source of frustration in week one. Switch to local Python later once coding feels normal.

2. Prove it works

In a new Colab notebook, click the + Code cell, type this, and press Shift+Enter:

print("hello, AI/ML")

If you see hello, AI/ML printed below the cell, Python works. That's it — that's your first program.

3. Git & GitHub — your portfolio, from day one

Every project you build in this course goes on GitHub. Employers check it. Set it up now, not later:

  1. Create a free account at github.com
  2. Follow GitHub's own "Hello World" quickstart to create your first repository
  3. Name it something like ai-ml-learning-log — this becomes the home for everything you build in this course

You don't need to understand Git deeply yet — just get one repository created and one file committed. We'll use it properly starting with your first real project in Phase E.

Try it — before looking below

Q1. Why start with Google Colab instead of installing Python locally on day one?

It removes install problems as a blocker — you can start writing and running code in the browser immediately, with nothing to configure.
