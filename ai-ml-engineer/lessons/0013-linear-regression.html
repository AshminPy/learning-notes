Linear regression from scratch

Linear regression is the simplest machine learning model, and almost every other model builds on the same idea. The job: fit a straight line through your data, so you can predict a number for new inputs you haven't seen yet.

Simple example: imagine you know how many hours 6 students studied, and their exam scores. If you plot "hours studied" on one axis and "score" on the other, the points roughly form a line going up and to the right. Linear regression finds the single best straight line through those points — then you can use that line to guess the score of a 7th student, just from their hours studied.

The equation: y = wx + b

A straight line is described by one small equation:

y = w * x + b
  • x — the input (hours studied)
  • y — the prediction (predicted exam score)
  • w — the weight (also called the slope). It says how much y changes when x goes up by 1. A bigger w means a steeper line — each extra hour studied buys you more score.
  • b — the bias (also called the intercept). It's the value of y when x is 0 — where the line crosses the vertical axis. Think of it as a starting score before any studying at all.

"Training" a linear regression model means one thing only: finding the w and b that make the line fit the actual data points as closely as possible. You don't pick w and b by hand — the algorithm works them out from the data. How it does that is the topic of the next lesson (cost function & gradient descent). For now, just know that fitting = finding the best w and b.

This is the same weighted sum from Lesson 10

In Lesson 10 you saw the dot product: multiply each input by a weight, then add everything up. y = w * x + b is exactly that idea, just with one input for now:

y = (w * x) + b
    ^weighted   ^bias added
     input       on top

Later, when a model has many inputs (hours studied, hours slept, past grade, etc.), the equation grows into y = w1*x1 + w2*x2 + w3*x3 + b — a dot product of weights and inputs, plus one bias. Linear regression with one input is the smallest possible version of that same pattern. Learn it here, and the bigger models in later lessons will feel familiar instead of new.

Meet scikit-learn

scikit-learn (imported in code as sklearn) is a Python library full of ready-made machine learning algorithms. Instead of writing the line-fitting math yourself, you hand scikit-learn your data and it works out w and b for you. This is the first lesson where you'll use it — and you'll keep using it for most of the "Core Machine Learning" phase.

Every scikit-learn model follows the same two-step pattern:

  • .fit(X, y) — "learn from this data." X is your inputs, y is the correct answers.
  • .predict(X_new) — "now guess the answer for this new input."

Common trap: scikit-learn always expects X as a 2D list — a list of rows, even if each row has only one number. So one input column of hours looks like [[1], [2], [3]], not [1, 2, 3]. y, the answers, stays a plain flat list: [50, 55, 65].

Try it — before looking below

Q1. In y = w * x + b, which letter controls how steep the line is?

w, the weight (slope) — a bigger w means y rises faster as x increases.

Q2. A model has w = 10 and b = 40. What score does it predict for someone who studied 3 hours?

70 — y = w*x + b = 10*3 + 40 = 70.

Try it before looking at the answer.

Reveal the reference answer

from sklearn.linear_model import LinearRegression

hours = [[1], [2], [3], [4], [5], [6]]
scores = [50, 55, 65, 70, 85, 90]

model = LinearRegression()
model.fit(hours, scores)

prediction = model.predict([[7]])
print(prediction)          # predicted score for 7 hours studied

print(model.coef_)         # the learned weight (w)
print(model.intercept_)    # the learned bias (b)

Recap
  • Linear regression fits a straight line, y = w * x + b, to predict a number.
  • w (weight/slope) controls steepness; b (bias/intercept) shifts the line up or down.
  • This is the same weighted-sum-plus-bias idea as the dot product from Lesson 10, just with one input.
  • scikit-learn's pattern is always: model.fit(X, y) to learn, then model.predict(X_new) to guess.
Not sure why X needs double brackets but y doesn't? Ask — that shape mismatch trips up almost everyone the first time.
