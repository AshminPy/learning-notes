Pandas: loading & exploring data

Real-world data almost never arrives as a clean list of numbers — it arrives as a table: rows of records, columns of fields, like a spreadsheet. Pandas is the Python library for working with tables of data. It is the tool you will use in nearly every AI/ML project to load, inspect, and clean data before it goes anywhere near a model.

Simple example: think of a spreadsheet of employees — one row per person, columns for name, age, and city. A pandas DataFrame is that spreadsheet, loaded into Python so you can query and manipulate it with code instead of clicking around a UI.

DataFrame vs Series

Pandas gives you two core data structures:

StructureShapeThink of it as
Seriesone-dimensionala single labeled column, or a single list of values
DataFrametwo-dimensionala full table — rows and columns, like a spreadsheet

A DataFrame is really just a collection of Series that share the same row labels — one Series per column.

Creating a DataFrame from a dict

The simplest way to build a small DataFrame is from a Python dictionary: each key becomes a column name, and each value (a list) becomes that column's data.

import pandas as pd

data = {
    "name": ["Priya", "Alex", "Sam", "Noor", "Lee"],
    "age": [25, 31, 28, 22, 35],
    "city": ["Delhi", "Toronto", "Austin", "Cairo", "Seoul"]
}

df = pd.DataFrame(data)
print(df)

Each list must be the same length — one entry per row. Run this in Colab and you'll see a neat table with row numbers (the index) on the left.

Exploring a DataFrame: .head(), .info(), .describe()

Once you have a DataFrame — even a huge one loaded from a file — these three methods are the first thing you run, every time:

MethodShows you
df.head()the first 5 rows (pass a number, e.g. df.head(10), for more)
df.info()column names, data types, and how many non-empty values each column has
df.describe()quick statistics for numeric columns — count, mean, std, min, 25%, 50%, 75%, max
df.head()
df.info()
df.describe()
Simple example: .head() is like glancing at the first page of a report to sanity-check it loaded correctly. .info() is like checking the report's table of contents and page count. .describe() is like getting a one-line statistical summary of every numeric column — useful for spotting outliers or mistakes before you trust the data.

Selecting one column

Use square brackets with the column name as a string to pull out a single column. This returns a Series, not a DataFrame:

ages = df["age"]
print(ages)
print(type(ages))   # <class 'pandas.core.series.Series'>

Try it — before looking below

Q1. You have a DataFrame df with columns name, age, city. What does df["city"] return — a DataFrame or a Series?

A Series — selecting a single column with square brackets always gives you back a one-dimensional Series, not a full table.

Q2. You just loaded a large DataFrame and want to quickly check the data types and whether any columns have missing values. Which method do you run?

df.info() — it prints each column's name, data type, and non-null (non-empty) count, so missing values stand out immediately.

Recap
  • Pandas works with tables: a DataFrame is 2-D (rows + columns), a Series is 1-D (a single column).
  • Build a small DataFrame from a dict: pd.DataFrame({"col": [...], ...}).
  • .head(), .info(), and .describe() are your first three checks on any new dataset.
  • Select one column with df["column_name"] — it returns a Series.
