1. Glossary — term → plain-English meaning

TermWhat it means
Weight (w) / Bias (b)The numbers a model adjusts during training — weight scales an input's importance, bias shifts the output. (Lesson 13)
Cost / loss functionA single number measuring how wrong the model's predictions are right now. (Lesson 14)
Gradient descentThe algorithm that nudges weights step by step to make the loss smaller — "walk downhill on the cost surface." (Lesson 14)
Learning rateHow big each gradient-descent step is. Too big overshoots, too small is slow. (Lesson 14)
Classification vs regressionRegression predicts a number (price, score); classification predicts a category (spam/not-spam). (Lessons 13, 15)
SigmoidA function that squashes any number into a 0-1 probability, used in logistic regression. (Lesson 15)
Train/test splitHolding back some data the model never trains on, so you can honestly check how it does on new data. (Lesson 16)
Overfitting vs underfittingOverfitting = memorized the training data, fails on new data. Underfitting = too simple to learn the pattern at all. (Lesson 16)
Confusion matrixA table of True/False Positives/Negatives — the raw material every classification metric is built from. (Lesson 17)
Precision / Recall / F1Precision = of what I flagged positive, how much was right. Recall = of all actual positives, how much did I catch. F1 balances both. (Lesson 17)
NeuronA weighted sum of its inputs, plus a bias, passed through an activation function — literally a dot product. (Lessons 10, 19)
Activation function (ReLU, sigmoid)Adds non-linearity so stacked layers can learn more than a straight line could. (Lesson 19)
Forward passInput flows through the network's layers to produce a prediction. (Lesson 20)
BackpropagationSends the error backward through the network so gradient descent can update every weight in every layer. (Lesson 20)
EpochOne full pass of training over the entire training set. (Lesson 20)
Decision tree / Random ForestA flowchart of yes/no splits; a Random Forest is many trees voting together. (Lesson 22)
Clustering / k-meansGrouping unlabeled data by similarity — no correct answer to check against. (Lesson 24)
Convolution / CNNA small filter sliding over an image looking for patterns like edges — the basis of computer vision models. (Lesson 26)
EmbeddingA word (or item) represented as a vector, positioned so similar meanings end up close together. (Lesson 27)
Attention / TransformerA mechanism letting a model weigh every other word's relevance when processing one word — the architecture behind modern LLMs. (Lesson 28)
Foundation modelA large pre-trained model (usually a transformer) adaptable to many downstream tasks. (Lesson 31)
RAG (Retrieval-Augmented Generation)Giving a model relevant documents at request time so it can answer using information it wasn't trained on. (Lesson 31)

4. Common interview questions — quick recall

If you can answer all of these cold, without looking, you're ready. Full model answers and links back to the teaching lesson: Lesson 33.

  • What is overfitting, and how do you detect it?
  • Explain gradient descent in one sentence.
  • What's the difference between precision and recall — and when would you prioritize one over the other?
  • What is a neural network, in plain terms?
  • Supervised vs unsupervised vs reinforcement learning — one example each.
  • Why do we split data into train and test sets?
  • Walk me through one of your projects: problem, approach, results, what you'd improve.
