Probability & statistics essentials

ML models learn patterns from data, and data always has spread — some values close together, some far apart. To describe that spread with numbers, you need two ideas: the mean (the center) and the standard deviation (how far things scatter from the center). You also need probability — the language models use to say "how sure am I?" instead of a flat yes/no.

Simple example: imagine two classrooms. Both have an average test score of 70. In Room A, everyone scored between 65 and 75. In Room B, scores ranged from 20 to 100. Same mean, totally different spread. The mean alone hides this — you need standard deviation to see it.

Mean — the center of the data

The mean (average) is the sum of all values divided by how many values there are.

data = [2, 4, 4, 4, 5, 5, 7, 9]

mean = sum(data) / len(data)
print(mean)   # 5.0

Add up 2+4+4+4+5+5+7+9 = 40. There are 8 numbers. 40 / 8 = 5. The mean is 5.

Variance and standard deviation — how spread out the data is

To measure spread, you look at how far each value is from the mean, square those distances (so negatives don't cancel positives), and average them. That average is the variance. The standard deviation is just the square root of the variance — it puts the spread back into the same units as your original data.

Sum of squared distances = 9+1+1+1+0+0+4+16 = 32. Divide by 8 values: variance = 32 / 8 = 4. Square root of 4 = 2. So the standard deviation is 2 — on average, values sit about 2 away from the mean of 5.

Common trap: a small standard deviation means the data is tightly clustered (predictable). A large one means the data is spread wide (noisy). In ML, features with wildly different spreads can confuse a model — this is part of why you often scale data before training (more on that in a later lesson).

Probability — a number from 0 to 1

Probability is just a number between 0 and 1 that says how likely something is. 0 means "will never happen." 1 means "will definitely happen." 0.5 means "50-50, a coin flip." 0.85 means "85% likely."

Why this matters for ML

Most ML models don't give you a hard yes/no. They give you a probability, and you decide the cutoff. A spam filter doesn't say "this email is spam." It says "there's an 85% chance this is spam" — and your app decides that anything above, say, 50% gets moved to the spam folder.

This matters because it lets you tune how cautious the system is. Want fewer false alarms? Raise the cutoff to 90%. Want to catch everything, even risky guesses? Lower it to 30%. A hard yes/no answer would take that control away from you.

In your Colab notebook, write a program that:

  • defines a list data = [3, 7, 7, 19, 23, 3, 5, 17]
  • computes the mean using plain Python (sum() and len())
  • imports numpy and computes the mean again with np.mean(), plus the standard deviation with np.std()

Reveal the reference answer

import numpy as np

data = [3, 7, 7, 19, 23, 3, 5, 17]

# Plain Python
mean_plain = sum(data) / len(data)
print("Mean (plain Python):", mean_plain)

# NumPy
mean_np = np.mean(data)
std_np = np.std(data)
print("Mean (NumPy):", mean_np)
print("Standard deviation (NumPy):", std_np)

Recap
  • Mean = sum of values divided by count — the center of the data.
  • Variance = average squared distance from the mean; standard deviation = square root of variance — both measure spread.
  • Probability is a number from 0 to 1 describing how likely something is.
  • ML models usually output a probability (e.g. "85% chance this is spam"), not a hard yes/no — you choose the cutoff.
