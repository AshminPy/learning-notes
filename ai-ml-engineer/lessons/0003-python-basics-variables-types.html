Python basics: variables, types, print/input

Every AI model, at the bottom, is just numbers and text being stored and passed around. A variable is a labeled box that holds one of those values. This lesson: create boxes, look inside them, and ask the user for input.

Variables

Simple example: a variable is like a sticky note on a box. The note is the name, the box holds the value. age = 25 means "put 25 in a box, and stick a note on it that says age."

age = 25
name = "Priya"
is_learning = True

print(age)
print(name)
print(is_learning)

Run this in your Colab notebook from Lesson 2. You should see three lines printed: 25, Priya, True.

The four types you'll use constantly

TypeExampleUsed for
int25Whole numbers — counts, ages, pixel positions
float3.14Decimal numbers — almost everything in ML math is a float
str"Priya"Text — quotes required, single or double
boolTrue / FalseYes/no, on/off — capital T and F, always

Python figures out the type automatically from how you write the value — you never have to declare it yourself. Check a variable's type with the built-in type() function:

print(type(age))        # <class 'int'>
print(type(name))       # <class 'str'>

print() and input()

print() shows a value. input() asks the person running the program to type something, and gives you back what they typed — always as a string.

your_name = input("What's your name? ")
print("Hello, " + your_name)

Common trap: input() always returns a string, even if the person types a number. input("Enter your age: ") gives you the string "25", not the number 25. Fix it with int(...): age = int(input("Enter your age: ")).

Try it — before looking below

Q1. What type is the value 17.5?

float — it has a decimal point.

Q2. You write age = input("Age: ") and the person types 30. What type is stored in age right now?

str — "30", not the number 30. input() always returns text, no matter what was typed.

Now write your own

In your Colab notebook, write a program that:

  • asks the user for their name and their age (as a number)
  • stores each answer in a variable with a sensible name
  • prints a sentence combining both, e.g. Priya is 25 years old.

Try it before looking at the answer.

Reveal the reference answer

name = input("What's your name? ")
age = int(input("What's your age? "))

print(name + " is " + str(age) + " years old.")

Recap
  • A variable is a named box for a value: name = value.
  • Four core types: int, float, str, bool.
  • input() always returns a string — convert with int(...) or float(...) when you need a number.
