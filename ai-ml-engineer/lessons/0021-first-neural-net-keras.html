Building your first neural net with Keras

In Lesson 19 you learned that a neural network is layers of neurons connected together. In Lesson 20 you learned that training means running a loop — predict, measure error, adjust weights — over and over with backpropagation and gradient descent. Writing that loop by hand, with all the calculus, would take pages of code. Keras is the library that builds and trains those exact networks for you, in a handful of lines. It ships inside TensorFlow, the ML platform built by Google.

Simple example: think of Lessons 19-20 as you learning to drive a manual car — you had to understand the clutch, the gears, the engine. Keras is the automatic transmission. You still need to know what a gear is, or you won't know what to ask for — but day to day, you just tell it "go" and it handles the mechanics.

The four Keras steps

Almost every Keras project follows the same four steps. We'll connect each one back to what you already know.

1. Build the model — Sequential and Dense

A Sequential model is a plain stack of layers, one after another — data flows in the top and out the bottom. A Dense layer is a layer where every neuron connects to every neuron in the layer before it (this is exactly the "layers of neurons" picture from Lesson 19).

model = tf.keras.Sequential([
    tf.keras.layers.Flatten(input_shape=(28, 28)),
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dense(10)
])

Flatten just reshapes a 28×28 grid of pixels into one long line of 784 numbers — networks read a flat list of numbers, not a grid. Then Dense(128, activation='relu') is a hidden layer of 128 neurons. Dense(10) is the output layer — 10 neurons, one per class the network is choosing between.

2. Compile the model — optimizer and loss

Before training starts, the model needs to know two things: how to measure how wrong it is, and how to correct itself. That's exactly the cost function (Lesson 14) and gradient descent (Lesson 14/20) pairing.

model.compile(optimizer='adam',
              loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
              metrics=['accuracy'])
  • loss — the cost function. It scores how far the prediction is from the true answer.
  • optimizer — the algorithm that adjusts the weights to reduce that loss. 'adam' is a smarter, faster relative of the plain gradient descent from Lesson 14.
  • metrics — extra numbers to report while training, purely for you to watch. 'accuracy' doesn't affect training itself.

3. Train the model — .fit()

This is the training loop from Lesson 20, running automatically.

model.fit(train_images, train_labels, epochs=10)

One epoch means the model has seen every training example once. epochs=10 runs the whole predict-measure-adjust loop 10 times over the full dataset.

4. Evaluate the model — .evaluate()

Once training is done, you check performance on data the model has never seen — the test set — to see if it actually learned, or just memorized.

test_loss, test_acc = model.evaluate(test_images, test_labels, verbose=2)
print('Test accuracy:', test_acc)

Q1. Which Keras step corresponds to Lesson 14's "cost function"?

The loss argument inside model.compile(). It measures how wrong the model's predictions are.

Q2. Your model has Dense(128, activation='relu') then Dense(10). How many neurons are in the output layer, and what does that number usually match?

10 neurons — it matches the number of classes the model is choosing between (one output neuron per possible answer).

Now write your own

Open a fresh Colab notebook. We'll train a small network on Fashion MNIST — 70,000 small grayscale images of clothing (t-shirts, shoes, bags, etc.), a standard beginner dataset that comes built into Keras.

Steps:

  • Import TensorFlow.
  • Load the Fashion MNIST dataset with tf.keras.datasets.fashion_mnist.load_data(). It returns a training set and a test set, already split.
  • Scale the pixel values from the 0-255 range down to 0-1 (dividing by 255.0) — networks train better on small numbers.
  • Build a Sequential model: Flatten → Dense(128, activation='relu') → Dense(10).
  • compile() it with the 'adam' optimizer and SparseCategoricalCrossentropy loss.
  • fit() it for 10 epochs.
  • evaluate() it on the test set and print the test accuracy.

Try writing it yourself before revealing the answer below. Expect roughly 88-91% accuracy — don't worry about tuning it further, the goal here is just to see the four steps run end to end.

Reveal the reference answer

import tensorflow as tf

fashion_mnist = tf.keras.datasets.fashion_mnist
(train_images, train_labels), (test_images, test_labels) = fashion_mnist.load_data()

train_images = train_images / 255.0
test_images = test_images / 255.0

model = tf.keras.Sequential([
    tf.keras.layers.Flatten(input_shape=(28, 28)),
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dense(10)
])

model.compile(optimizer='adam',
              loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
              metrics=['accuracy'])

model.fit(train_images, train_labels, epochs=10)

test_loss, test_acc = model.evaluate(test_images, test_labels, verbose=2)
print('Test accuracy:', test_acc)
