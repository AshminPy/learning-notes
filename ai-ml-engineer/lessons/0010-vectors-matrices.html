Vectors, matrices, dot product — the intuition

You already used a vector and a matrix in Lessons 7 and 8 — you just didn't call them that. This lesson gives you the two words, plus one calculation (the dot product) that shows up inside almost every model you'll ever train.

A vector is just a list of numbers

A vector is a list of numbers that together describe one thing. The NumPy array from Lesson 7 — np.array([2, 3, 4]) — is a vector. Nothing new to install or import; it's the same object, new name.

Simple example: a house could be described by the vector [3, 2, 1500] — 3 bedrooms, 2 bathrooms, 1500 square feet. Each position in the list is a feature. The order matters: position 1 always means "bedrooms," position 3 always means "square feet," for every house you describe this way.

A matrix is a grid of numbers

A matrix is a 2-D grid of numbers — rows and columns. You already met one: the pandas DataFrame from Lesson 8 is a matrix (plus row/column labels on top). Each row is one example (one house, one customer, one email); each column is one feature (bedrooms, age, word count).

This is exactly what a dataset is for machine learning: a matrix where rows = examples and columns = features. Each row of this matrix, on its own, is a vector — the vector for house 1 is [3, 2, 1500].

The dot product: multiply, then add

The dot product of two vectors (same length) is: multiply the numbers in matching positions, then add up all the results. That's the whole idea.

Simple example: receipt math. You buy 2 coffees at $0.50 and 3 muffins at $0.50 — wait, let's use different prices. Quantities [2, 3], prices [4, 5]. Total cost = (2 × 4) + (3 × 5) = 8 + 15 = 23. That's a dot product — multiply matching positions, add them up.
a = [2, 3]
b = [4, 5]

dot = (a[0] * b[0]) + (a[1] * b[1])
    = (2 * 4) + (3 * 5)
    = 8 + 15
    = 23
Common trap: from Lesson 7, * on two NumPy arrays multiplies elementwise and gives you back an array — [8, 15], not 23. The dot product is a different operation: multiply elementwise, then sum everything into one single number. In NumPy that's np.dot() or the @ operator, not *.

Why the dot product matters: it's what a neuron does

This is the part that makes it worth learning. A single "neuron" in a neural network (and a plain linear model like linear regression) does exactly this calculation on its inputs:

  1. Take the input features as a vector — e.g. a house's [bedrooms, bathrooms, sqft].
  2. Take a weight for each feature — a number saying how much that feature matters — as a vector of the same length.
  3. Compute the dot product of features and weights: multiply matching positions, add them up. This gives one number — a weighted sum.

That single number is the model's raw prediction (before any extra adjustment). Training a model is largely the process of finding the weight values that make this weighted sum as accurate as possible, across every row in your dataset. Every layer of a deep neural network is just many of these dot products, run in parallel, stacked on top of each other.

Try it — before looking below

Q1. Vectors a = [1, 2, 3] and b = [4, 0, 2]. What is their dot product?

10 — (1×4) + (2×0) + (3×2) = 4 + 0 + 6 = 10.

Q2. A dataset has 200 rows and 5 columns. In matrix terms, what do the 200 and the 5 represent?

200 = the number of examples (rows); 5 = the number of features (columns). Each row, read alone, is a feature vector for one example.

Now write your own

In your Colab notebook, use NumPy to compute the dot product of a feature vector and a weight vector, and interpret the result as a weighted sum:

  • create features = np.array([2, 3])
  • create weights = np.array([0.5, 0.5])
  • compute the dot product with np.dot(features, weights) (or features @ weights)
  • print the result and write a one-line comment explaining what it represents

Try it before looking at the answer.

Reveal the reference answer

import numpy as np

features = np.array([2, 3])
weights = np.array([0.5, 0.5])

result = np.dot(features, weights)
print(result)   # 2.5

# result = (2*0.5) + (3*0.5) = 1.0 + 1.5 = 2.5
# This is the weighted sum a single neuron/linear model
# would compute from these two input features.

# Same result using the @ operator instead of np.dot():
result2 = features @ weights
print(result2)  # 2.5

Source

numpy.org/doc/stable/reference/generated/numpy.dot.html — the official NumPy documentation for np.dot(): for two 1-D arrays it computes "the inner product of vectors" — multiply matching positions and sum, exactly as covered above.

Recap
  • A vector is a list of numbers describing one thing (a NumPy array). A matrix is a grid of numbers (a DataFrame) — rows = examples, columns = features.
  • Dot product: multiply matching positions, add the results, get one number.
  • In NumPy, use np.dot() or @ for the dot product — * alone only multiplies elementwise, it does not sum.
  • A dot product of features and weights is a weighted sum — the core calculation a single neuron or linear model performs.
