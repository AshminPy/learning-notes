How training works: forward pass & backpropagation intuition

In Lesson 19 you built a neural network out of neurons and layers. But a brand new network is useless — its weights are random guesses. This lesson explains, in plain words, how a network goes from "random guesses" to "actually good at the task." Two words to know: forward pass and backpropagation.

Simple example: imagine you're learning to throw darts blindfolded. You throw (forward pass), someone tells you how far you missed the bullseye and in which direction (loss), and you adjust your arm angle a little to correct for that miss (backpropagation). Throw again. Over hundreds of throws, your aim gets better. A neural network learns the exact same way — throw, check the miss, adjust, repeat.

Step 1: the forward pass

The forward pass is just what you already learned in Lesson 19: the input numbers flow into the first layer of neurons, each neuron does its little calculation, passes its output to the next layer, and so on until the last layer spits out a prediction. Data moves forward, layer by layer, left to right. That's the whole forward pass — nothing new here, just running the network once.

Step 2: compute the loss

Now the network has a prediction. But is it any good? You compare it to the real answer (the label you already know, from your training data) using a loss function — the same idea from Lesson 14. The loss is a single number that says "how wrong was this prediction." Big loss = way off. Small loss = close. Zero loss = perfect.

At the start of training, with random weights, the loss is usually huge. The whole goal of training is to make that number small.

Step 3: backpropagation — send the error backward

Here is the new idea. Once we know the loss (how wrong we were), we need to figure out: which weights caused the mistake, and how should each one change to make the mistake smaller next time?

Backpropagation is the process of sending that error signal backward through the network, layer by layer, from the output back toward the input. As the error travels backward through each layer, the network works out — for every single weight in that layer — "if I nudge this weight up a little, does the error get better or worse? By how much?" That's it. No new math tool here — this is exactly gradient descent from Lesson 14, just applied many times over, once for every weight in every layer, instead of just one weight in a simple regression line.

Simple example: think of a company where a customer complaint (the error) travels backward through the chain of command — from the CEO, to the department head, to the team lead, to the individual worker. At each level, that person asks "was my decision part of the problem, and which way should I adjust next time?" Backpropagation is that same complaint working its way backward through the network's layers, with each weight asking "was I part of the mistake, and which way should I move?"

Step 4: update the weights

Once every weight knows which direction would have reduced the error, the network nudges each weight a small step in that direction — same "small step" idea as gradient descent in Lesson 14. Not a huge jump (that would overshoot and cause chaos), just a small, careful nudge. Then the whole cycle starts again with a new example.

Putting the four steps together

StepWhat happensWhere you've seen this before
1. Forward passInput flows through the layers, network produces a predictionLesson 19 — neurons and layers
2. Compute lossCompare prediction to the real answer, get one "how wrong" numberLesson 14 — cost/loss function
3. BackpropagationSend the error backward, work out which direction each weight should moveLesson 14 — gradient descent, applied to every weight in every layer
4. Update weightsNudge every weight a small step in the direction that reduces errorLesson 14 — the "small step" update rule

One full trip through all four steps, on one training example, is one round of training. Do this for every example in your training set, and you've completed one epoch — one full pass through the whole training set. Training a network usually means repeating this for many epochs, seeing the same data again and again, each time with slightly better weights than before.

Try it yourself

No code this time — just trace it through in your head, step by step. Imagine a tiny network that predicts "will this email get a reply" (yes/no) and it just saw one training email that should be labeled "yes" but the network predicted "no."

  • What happens in the forward pass for this email? (What does the network produce?)
  • What does the loss look like here — small or large? Why?
  • During backpropagation, is the error signal traveling from the input layer to the output layer, or from the output layer back to the input layer?
  • After the weights update, would you expect this same network, shown this exact email again right away, to be slightly more or slightly less likely to predict "yes"?

Think through your answers before you move on — there's no single "correct" wording, but the direction of each answer should match the steps above.

Check your understanding

Q1. Put these four steps in the correct order: (a) update weights, (b) compute loss, (c) forward pass, (d) backpropagation.

c, b, d, a — forward pass first (get a prediction), then compute loss (how wrong were we), then backpropagation (send the error backward to find each weight's direction), then update weights (take the small step). Then repeat with the next example.

Q2. Suppose a network only ever did the forward pass, over and over, and never ran backpropagation or updated its weights. What would happen to its predictions over time?

Nothing would improve. The weights would stay exactly as they started (random), so the network would keep making the same quality of predictions forever — no matter how many times you ran it, or how much training data you showed it. Learning only happens in the backpropagation + weight update steps. Running the forward pass alone is just "using" the network, not "training" it.

Q3. True or false: backpropagation is a completely different technique from gradient descent — they just happen to look similar.

False. Backpropagation is gradient descent — it's the same "find the direction that reduces error, take a small step that way" idea from Lesson 14, just applied to every weight in every layer of a multi-layer network, instead of one weight in a simple line.

Source

developers.google.com/machine-learning/crash-course/neural-networks/backpropagation — Google's Machine Learning Crash Course, which describes backpropagation as "the most common training algorithm for neural networks" that "makes gradient descent feasible for multi-layer neural networks."

Recap
  • Forward pass: input flows through the network's layers and produces a prediction.
  • Loss: compare the prediction to the real answer to get a single "how wrong" number (Lesson 14).
  • Backpropagation: send that error backward through the layers so every weight learns which direction would reduce it — this is gradient descent applied to every weight in every layer, not a new technique.
  • One forward + backward + update on one example = one training step. One full pass through the whole training set = one epoch.
If "sending the error backward" still feels fuzzy, that's completely normal — most learners need to sit with this one for a day before it clicks. Ask away, one question at a time.
