Neural networks: neurons, layers, activation functions

You already know the math behind a neural network — you learned it in Lesson 10. A neuron is nothing more than a dot product (a weighted sum) with one extra step bolted on. This lesson names that extra step, shows why we stack neurons into layers, and why that extra step is what makes stacking worth doing at all.

A neuron is the dot product you already know

Back in Lesson 10 you learned: take input features as a vector, take a weight for each feature, multiply matching positions and add them up — that gives you one number, a weighted sum. That is exactly what one neuron computes. Nothing new here.

A real neuron adds two small things on top of the plain dot product:

  1. A bias — one extra number added at the end, not tied to any input. It lets the neuron shift its output up or down, the same way the + c in y = mx + c shifts a line.
  2. An activation function — a small function applied to the result, which decides what the neuron actually outputs.

So the full formula for one neuron is:

output = activation( (input1 * weight1) + (input2 * weight2) + ... + bias )
         \_______________ dot product ________________/   \___/   \____________/
                     (Lesson 10)                            new       new
Simple example: think of a neuron as a bouncer at a club door checking a few signals — are you on the guest list (weight 1), did you arrive before midnight (weight 2). Each signal gets multiplied by how much the bouncer cares about it, the results are added up, then the bouncer's own mood that night (the bias) shifts the total. The activation function is the bouncer's final yes/no rule applied to that total — not just "sum up the evidence" but "decide something based on it."

Why stack neurons into layers

One neuron only makes one weighted decision. Real problems need many small decisions combined. So we arrange neurons into layers:

LayerJob
Input layerNot really neurons — just holds the raw feature values you feed in (e.g. bedrooms, bathrooms, sqft).
Hidden layer(s)Each neuron here takes every value from the previous layer, computes its own weighted sum + bias, and applies an activation function. A network can have one hidden layer or many — "deep" learning just means "many hidden layers."
Output layerThe final neuron(s) that produce the answer — e.g. one neuron outputting a price, or a few neurons outputting class probabilities.

Every value flows forward: input layer → hidden layer → hidden layer → ... → output layer. Each connection between two neurons has its own weight, learned during training (that's Lesson 20).

Why nonlinearity matters — the activation function is not optional

Here is the part beginners usually skip, and it is the most important idea in this lesson: if every neuron only computed a weighted sum with no activation function, stacking layers would be mathematically pointless. A dot product feeding into another dot product feeding into another dot product collapses into... one single dot product. Ten layers of plain weighted sums behave exactly like one layer. You'd gain nothing from the "depth" in deep learning.

The activation function breaks that collapse. It bends the output — it is nonlinear — so stacking layers actually builds something new each time: more complex shapes and patterns than any single layer could represent alone. This is the entire reason neural networks can learn things like image recognition or language, which no straight line or flat weighted sum could ever capture.

Two activation functions to know now

NameRuleTypical use
ReLU (Rectified Linear Unit)Negative numbers become 0. Positive numbers stay the same.The default choice for hidden layers in most modern networks — cheap to compute, works well in practice.
SigmoidSquashes any number into a range between 0 and 1.Common in the output layer for yes/no (binary classification) problems, where you want a probability — you already met this exact function in Lesson 15's logistic regression.
Simple example — ReLU by hand: ReLU(-3) = 0. ReLU(0) = 0. ReLU(4) = 4. That's the whole function: max(0, x). Anything below zero gets clipped to zero; anything zero or above passes through unchanged.

Try it yourself — compute one neuron by hand

A neuron has 2 inputs, 2 weights, and a bias:

  • input1 = 3, weight1 = 0.5
  • input2 = 4, weight2 = -1
  • bias = 1

Do this on paper before revealing the answer:

  1. Compute the weighted sum: (input1 * weight1) + (input2 * weight2) + bias
  2. Apply ReLU to that result.

Reveal the worked answer

weighted sum = (3 * 0.5) + (4 * -1) + 1
             = 1.5 + (-4) + 1
             = -1.5

ReLU(-1.5) = 0   # negative, so it gets clipped to 0

Final neuron output: 0

Check your understanding

Q1. What two things does a neuron add on top of the plain dot product from Lesson 10?

A bias (one extra number added at the end) and an activation function (applied to the weighted sum + bias to produce the final output).

Q2. If you stacked 5 layers but removed every activation function, how would that network behave compared to a single layer?

Exactly the same as one layer. Without nonlinear activation functions, stacked weighted sums collapse into a single weighted sum — depth adds nothing.

Q3. A neuron's weighted sum + bias comes out to -7. What does ReLU output for that neuron?

0 — ReLU turns any negative number into 0.

Recap
  • A neuron = the Lesson 10 dot product (weighted sum) + a bias, then passed through an activation function.
  • Layers stack neurons: input layer → hidden layer(s) → output layer, with weights on every connection.
  • Without a nonlinear activation function, stacking layers is mathematically identical to one layer — activation functions are what make "deep" learning actually deeper.
  • ReLU: negative → 0, positive → unchanged. Sigmoid: squashes any number into 0–1, used for probabilities.
Not sure why a bias is needed, or why "nonlinear" matters? Ask — this is the concept that unlocks everything else in deep learning, worth getting solid before Lesson 20.
