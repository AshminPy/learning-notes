NumPy: arrays & vectorized math

Every ML library you'll ever use — scikit-learn, TensorFlow, PyTorch — stores its numbers in one thing underneath: a NumPy array. This lesson shows why that array exists, and the handful of moves you'll use with it constantly.

Why not just use a Python list?

A Python list can hold numbers, but it's slow when you have a lot of them and need to do math on all of them at once. Python has to loop through the list one item at a time, checking each item's type as it goes. NumPy arrays fix this: all the numbers are packed together in memory as one type, so NumPy can do the math on all of them in one fast step — this is called vectorization.

Simple example: a Python list is like a box of mixed items you have to check one by one. A NumPy array is like a carton of eggs — same shape, same type, packed tight — so you can tilt the whole carton at once instead of moving each egg by hand.

Creating an array

Import NumPy (the usual short name is np), then build an array from a Python list with np.array():

import numpy as np

a = np.array([2, 3, 4])
print(a)          # [2 3 4]
print(a.shape)     # (3,)

.shape tells you the size of the array along each dimension, as a tuple. (3,) means "1 dimension, 3 items." A grid of numbers (like a mini spreadsheet) would show (rows, columns), e.g. (2, 3) for 2 rows and 3 columns.

Elementwise math: the whole point of NumPy

With a Python list, to multiply every number by 2 you must loop:

# Python list — manual loop
numbers = [1, 2, 3, 4, 5]
doubled = []
for n in numbers:
    doubled.append(n * 2)
print(doubled)     # [2, 4, 6, 8, 10]

With a NumPy array, you write the operation once and it applies to every element automatically. This is called an elementwise operation:

# NumPy array — no loop needed
numbers = np.array([1, 2, 3, 4, 5])
doubled = numbers * 2
print(doubled)     # [ 2  4  6  8 10]

Addition works the same way: numbers + 10 adds 10 to every element. Two arrays of the same shape can also be combined directly, e.g. a - b subtracts them position by position — no loop, no index tracking.

Common trap: on a NumPy array, * multiplies each element by the number — it does not do matrix multiplication like in linear algebra. That's a different operation (@ or .dot()), which you'll meet later. For now, just remember * on an array = elementwise.

Indexing and slicing — same rules as lists

A 1-dimensional NumPy array is indexed and sliced exactly like a Python list from Lesson 6:

a = np.array([10, 20, 30, 40, 50])

print(a[0])        # 10   — first item
print(a[2:4])      # [30 40]  — slice, index 2 up to (not including) 4
print(a[::-1])     # [50 40 30 20 10]  — reversed

Q2. Why is a NumPy array faster than a Python list for math on a large amount of numbers?

All the values are packed together as one type, so NumPy applies the operation to every element in one fast step (vectorized), instead of Python looping through one item at a time.

Recap
  • NumPy arrays are fast because operations apply to every element at once (vectorized) — no manual loop.
  • Create one with np.array([...]); check its size with .shape.
  • * and + on an array apply elementwise to every item.
  • Indexing and slicing (a[0], a[2:4]) work the same as Python lists.
