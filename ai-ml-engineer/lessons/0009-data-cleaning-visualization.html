Data cleaning & visualization

Real-world data is never as clean as the example tables in Lesson 8. Sensors fail, people skip survey questions, systems log the same event twice. Before any of that data goes into a model, you need to find the mess and either fix it or remove it — and you need to look at the data with your own eyes, not just trust the numbers.

Simple example: imagine a class attendance sheet where a few students forgot to sign in (missing values) and one student accidentally signed in twice (a duplicate). If you count attendance without checking for these, your count is wrong. Data cleaning is checking the sheet before you trust the count.

Why real data is messy

ProblemWhat it looks likeWhy it happens
Missing valuesan empty cell, or NaN (Not a Number)a sensor dropped a reading, a form field was left blank, a join found no match
Duplicatesthe exact same row appears more than oncea file was imported twice, an event was logged twice, a form was submitted twice

Pandas represents a missing value as NaN (or None for text/object columns). It behaves differently from a normal value — for example, NaN == NaN is actually False — so you always use pandas' own tools to find it, never a plain == comparison.

Finding missing values: .isna()

df.isna() returns a same-shaped table of True/False, where True means "this cell is missing." Combine it with .sum() to count missing values per column:

import pandas as pd
import numpy as np

data = {
    "name": ["Priya", "Alex", "Sam", "Noor", "Lee"],
    "score": [88, 92, np.nan, 79, 95]
}
df = pd.DataFrame(data)

print(df.isna())
print(df.isna().sum())   # count of missing values per column

Fixing missing values: .dropna() and .fillna()

Once you find missing values, you have two basic options:

MethodWhat it doesUse when
df.dropna()removes any row that has at least one missing valueyou have plenty of rows and can afford to lose a few
df.fillna(value)replaces missing values with something — a fixed number, or a computed one like the column averageyou don't want to lose rows, and a reasonable "fill-in" value exists
df_dropped = df.dropna()               # rows with any NaN are gone
df_filled = df.fillna(df["score"].mean())   # fill NaN with the average score

Neither method changes df itself unless you pass inplace=True or reassign it (df = df.fillna(...)) — by default, both return a new DataFrame.

Duplicates get a similar pair of tools: df.duplicated() flags repeated rows as True/False, and df.drop_duplicates() removes them. Same pattern as missing values — find first, then decide how to fix. (Full details on missing-data handling: pandas.pydata.org/docs/user_guide/missing_data.)

You can't fix what you can't see

.describe() gives you numbers, but numbers hide shapes. A dataset can have the same average as another dataset and look completely different when plotted — one smooth, one with a wild outlier. This is why every data scientist plots data before modeling it: a chart shows a spike, a gap, or a weird cluster in a way a table of numbers never will.

Matplotlib is Python's foundational plotting library. You can use it two ways: call plt.plot() directly on raw values, or call .plot() straight on a DataFrame or Series (pandas uses matplotlib under the hood, so the result is the same).

import matplotlib.pyplot as plt

scores = [88, 92, 85, 79, 95]

plt.plot(scores)
plt.title("Scores")
plt.xlabel("Student index")
plt.ylabel("Score")
plt.show()

The DataFrame shortcut is even shorter — good for a quick look while exploring:

df["score"].plot()
plt.show()
Simple example: plt.plot() is like drawing a line connecting dots on graph paper, one dot per value, left to right. It's the simplest possible chart — and often the fastest way to spot something wrong in your data before you waste time training a model on it.

Try it — before looking below

Q1. You run df.isna().sum() and the age column shows 3. What does that 3 mean?

3 rows have a missing (NaN) value in the age column. .isna() marks each cell True/False for "is this missing", and .sum() adds up the Trues per column (Python treats True as 1).

Q2. You run df.fillna(0) but then print df and the missing values are still there. Why?

.fillna() returns a new DataFrame by default — it doesn't change df in place. You need to reassign it: df = df.fillna(0), or pass inplace=True.

Reveal the reference answer

import pandas as pd
import matplotlib.pyplot as plt

data = {
    "day": [1, 2, 3, 4, 5],
    "temperature": [21.5, 22.0, None, 23.5, 24.0]
}
df = pd.DataFrame(data)

print(df.isna())                 # shows True on the missing row

df["temperature"] = df["temperature"].fillna(df["temperature"].mean())
print(df)                        # missing value replaced with the average

df["temperature"].plot(title="Temperature by day")
plt.show()

Recap
  • Real data has missing values (NaN) and duplicates — always check before modeling.
  • df.isna() finds missing values, df.dropna() removes rows with them, df.fillna(value) replaces them.
  • Both .dropna() and .fillna() return a new DataFrame by default — reassign or use inplace=True to keep the change.
  • Plot before you model: plt.plot() or df["col"].plot() shows shapes and outliers a table of numbers hides.
