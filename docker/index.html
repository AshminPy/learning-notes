Docker Engineering — Zero to Hero

This site's linux and kubernetes-cka courses already teach container fundamentals (namespaces, cgroups, CRI) — this course starts one layer up: the Dockerfile, image, build, Compose, registry, and security-scanning tooling a working engineer actually uses day to day. No single certification anchors this course; it's built for real, daily Docker work, ending in a capstone that containerizes a real multi-service app end-to-end.
