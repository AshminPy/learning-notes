Storage basics: object, block, and file

GCP has three storage types. Pick by how the app needs to read the data — as objects, as a raw disk, or as a shared folder.

Simple example: object storage is a mailroom — you ask for a package by name. Block storage is a hard drive bolted to one computer. File storage is a shared folder many computers can open at the same time.

Cloud Storage — object storage

AWS analogue: S3. Whole files ("objects") in buckets, reached over HTTP. Good for backups, static assets, and ML training data — anything read as one blob, not mounted as a disk.

Persistent Disk — block storage

AWS analogue: EBS. A raw disk attached to one Compute Engine VM. Good for VM boot disks and databases that need a real filesystem.

Filestore — file storage

AWS analogue: EFS. Managed NFS that many VMs or Pods can mount at once. Good for GKE shared volumes and lift-and-shift apps that expect a normal filesystem.

Exam trap: Persistent Disk is zonal by default. If the scenario says "must survive a zone failure," a normal disk is not enough — you need a Regional Persistent Disk, or backups/snapshots in another zone.

Try it — before looking below

Q1. An app needs a shared filesystem that 20 GKE Pods can write to at once. Which service?

C. Filestore is the only one of the three built for many clients reading and writing the same filesystem at once.

Q2. A scenario says "must keep running if one zone fails." Plain Persistent Disk — safe or not?

B. A normal Persistent Disk lives in one zone. Losing that zone loses the disk unless you chose Regional PD.

Q3. Which storage type is closest to AWS S3?

B. Cloud Storage is object storage, same shape as S3 — buckets full of named objects, read over HTTP.

Source

docs.cloud.google.com/storage/docs/consistency and docs.cloud.google.com/compute/docs/disks/persistent-disks

Recap
  • Object = whole files by name (Cloud Storage). Block = raw disk on one VM (Persistent Disk). File = shared folder for many clients (Filestore).
  • Persistent Disk is zonal by default — Regional PD is the answer when a zone must be allowed to fail.
