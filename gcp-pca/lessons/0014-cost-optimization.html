GCP PCA — Lesson 14 of 17

Cost optimization

Three levers matter most for this exam: Committed Use Discounts, Sustained Use Discounts, and Spot VMs. Each trades something (flexibility, or reliability) for a lower price.

Simple example: a CUD is a phone contract — commit for a year, pay less per month. Sustained use is a loyalty discount — use it a lot, price drops automatically, no contract. A Spot VM is a stand-by flight ticket — cheap, but you can get bumped.

Committed Use Discounts (CUDs)

  • You commit to 1 or 3 years. In return, you get a big discount.
  • Resource-based — commit to a specific machine shape/region. Up to ~55% off (70% for memory-optimized, 3yr). Least flexible, biggest discount.
  • Spend-based (Flexible) — commit to a $/hour spend. Applies automatically across Compute Engine, GKE, Cloud Run. No region lock-in.

Sustained Use Discounts (SUDs)

Still active today — do not assume this was removed.

No commitment needed. If a machine runs more than ~25% of the month, GCP discounts it automatically. Up to 30% (older families like N1) or 20% (N2/N2D/C2). Free money on always-on workloads.

Spot VMs

  • Up to 91% off on-demand price.
  • Google can reclaim the machine anytime — short notice, no uptime guarantee.
  • No 24-hour runtime cap (unlike the old "preemptible VM" product).
  • Best for: stateless, checkpointable, fault-tolerant work — batch jobs, CI runners, ML training. Never for a database or anything needing constant uptime.
Exam trap: "cheapest" is not the same as "best." The Cost Optimization pillar means most value per dollar, not lowest bill. If a scenario states an uptime/SLA requirement, an all-Spot-VM answer that ignores it is a trap — even though it's the cheapest option on the page.

Try it — before looking below

Q1. A nightly batch ETL job can restart from a checkpoint if interrupted. A customer-facing API must stay up 24/7. Which lever goes where?

ETL job → Spot VM (checkpointable, interruption is cheap). API → CUD (steady, predictable, needs uptime — Spot would risk the SLA).

Quiz — Lesson 14

Q1. A workload runs 24/7 with steady, predictable needs for 3 years. Best discount lever?

A. A 3-year resource-based CUD gives the deepest discount for genuinely predictable, steady-state usage.

Q2. True or false: Sustained Use Discounts have been fully removed from GCP.

A. SUDs are still active, just narrower than before (mainly N1, N2/N2D, C2, M1/M2 families). Don't work from stale material here.

Q3. A scenario has both a cost goal and an explicit uptime SLA. What should you pick?

B. The Cost Optimization pillar means best value, not lowest price. A stated SLA is a hard constraint — the cheapest answer must still satisfy it.

Recap
  • CUD = commit for a discount (resource-based or spend-based).
  • SUD = automatic discount for heavy use, no commitment, still active.
  • Spot VM = up to 91% off, but can be reclaimed anytime — fault-tolerant work only.
  • Exam trap: cheapest is not automatically best — a stated SLA always wins.
