AI platform rename, and the event-driven glue

Flag this clearly: Google renamed Vertex AI to the Gemini Enterprise Agent Platform in April 2026. Same platform, new name. Study material and search results may still say "Vertex AI" — don't let that confuse you, answer by what the service does, not by which name is used.

Simple example: same restaurant, new sign. Vertex AI got a new sign — Gemini Enterprise Agent Platform. Same kitchen (train and deploy models), same menu (Model Garden of foundation models), just a new name on the door.

Vertex AI became Gemini Enterprise Agent Platform

What it is (unchanged)What to call it now
Managed ML platform: train, deploy, predictStill the core of Gemini Enterprise Agent Platform
Catalog of foundation models (Gemini, Claude, Gemma, Llama)Model Garden
Toolkit to build agents (SDK, low-code, templates)Agent Builder

Model Garden vs Agent Builder

Model Garden — pick a ready-made foundation model, no training needed. Agent Builder — build something that reasons, calls tools, and does multi-step work, not just one prompt in, one answer out.

Pub/Sub vs Eventarc vs Cloud Scheduler

ServiceTrigger typeTypical use case
Pub/SubMessage, published by your appDecouple services; fan out one event to many consumers
EventarcEvent, from a GCP serviceReact to a resource change (file uploaded) with no custom polling
Cloud SchedulerTime, cron scheduleNightly batch job, recurring cleanup

Fast filter: named moment in time → Scheduler. Something happened to a GCP resource → Eventarc. Your own app publishing data → Pub/Sub.

Exam trap: "trigger a Cloud Run function when a file lands in Cloud Storage" is Eventarc, not raw Pub/Sub — even though Eventarc uses Pub/Sub as transport underneath. You didn't build that plumbing, so it's not the Pub/Sub answer.

Try it — before looking below

Q1. What happened to the name "Vertex AI"?

B. Same platform, new brand, as of April 2026. Expect both names on the exam.

Q2. A scenario needs a multi-step agent that calls tools and reasons over documents. Best fit?

C. Agent Builder is for tool-using, multi-step agents. Model Garden just gives you a model to call.

Q3. A file lands in Cloud Storage and must trigger a Cloud Run function automatically, no custom polling. Best fit?

B. Eventarc standardizes the Storage event and routes it for you, retries included.

cloud.google.com/products/gemini-enterprise-agent-platform and docs.cloud.google.com/eventarc/docs/overview

Recap
  • Vertex AI was renamed to Gemini Enterprise Agent Platform (April 2026) — same platform, expect both names.
  • Model Garden = pick a model. Agent Builder = build a multi-step agent.
  • Pub/Sub = message you publish. Eventarc = GCP resource event. Scheduler = fixed time.
