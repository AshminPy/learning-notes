Deployment

A bare Pod has no memory. Kill it and it stays dead — nothing recreates it. A Deployment fixes that: it watches a Pod template and keeps the right number of copies running, always.

Simple example: think of a Deployment like a staffing agency with a standing order — "always keep 3 people on this shift." If one quits, the agency notices and sends a replacement. You never manage the individual worker.

What's inside a Deployment manifest

apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-nginx
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-nginx
  template:
    metadata:
      labels:
        app: my-nginx
    spec:
      containers:
        - name: nginx
          image: nginx

Three parts:

  • spec.replicas — how many Pod copies should exist
  • spec.selector.matchLabels — how the Deployment finds "which Pods are mine"
  • spec.template — a full Pod spec, embedded (this is the Pod manifest you already know)

Gotcha: spec.selector.matchLabels must exactly match spec.template.metadata.labels, or the Deployment is invalid.

A Deployment doesn't touch Pods directly — it creates and manages a ReplicaSet, and the ReplicaSet creates and watches the Pods. Update the image and re-apply: a new ReplicaSet is created and scaled up, the old one scaled to zero. That's a rolling update.

Try it — before looking below

Q1. What two fields must match for a Deployment to be valid?

spec.selector.matchLabels must match spec.template.metadata.labels.

Now write your own

Turn your Lesson 2 Pod into a Deployment with 3 replicas — by hand. It needs:

  • apiVersion: apps/v1, kind: Deployment (Pod is v1, Deployment is apps/v1)
  • spec.replicas: 3
  • spec.selector.matchLabels and spec.template.metadata.labels — same key/value

Apply it, then run kubectl get deploy, kubectl get rs, and kubectl get pods --show-labels. Try it before you look below.

Once it's running, try the operational payoff: kubectl rollout status deployment/my-nginx, kubectl rollout undo deployment/my-nginx, kubectl rollout history deployment/my-nginx.

Recap
  • A Deployment = Pod template + desired replica count + a selector that finds its own Pods.
  • spec.selector.matchLabels must match spec.template.metadata.labels.
  • A Deployment manages a ReplicaSet, which manages the Pods.
