The Filesystem Tree

Linux has exactly one filesystem tree, rooted at /. Unlike Windows' separate drive letters (C:\, D:\), a second disk gets mounted onto an existing directory — from then on, everything under that directory lives on the separate disk, but looks like any other part of the tree.

Simple example: think of it like one company org chart, not separate charts per office. A new office (a new disk) doesn't get its own chart — it's grafted onto the existing one at a specific reporting line (a mount point).

What lives where — the Filesystem Hierarchy Standard (FHS)

PathWhat's there
/etcSystem-wide configuration
/var/logLog files
/tmpTemporary files — often cleared on reboot
/home/<user>Personal files per user
/optThird-party software not managed by the package manager

Knowing this means you can guess where a problem lives instead of searching the whole disk — a misbehaving service's config is almost always under /etc, its logs almost always under /var/log.

Absolute vs relative paths

An absolute path starts with / and means the same thing from anywhere: /etc/nginx/nginx.conf. A relative path depends on your current directory: ../config/app.conf. Scripts and automation should use absolute paths — a relative path in a cron job, run from a different working directory than you tested in, can point at the wrong thing entirely.

Try it — before looking below

Q1. A cron job using a relative path works when you run it by hand, but fails at 3am when cron runs it. Why?

Cron doesn't start in the same working directory as your interactive shell — the relative path resolves against a different starting point, so it points somewhere else (or nowhere).

Now navigate your own system

pwd                  # print current directory (absolute path)
cd /var/log           # absolute path — works from anywhere
ls -la                # list all, including hidden files
cd -                  # jump back to your previous directory
find /etc -name "*.conf" -type f 2>/dev/null | head -5

Source

Filesystem Hierarchy Standard 3.0 — the official Linux Foundation specification.

Recap
  • One filesystem tree rooted at / — separate disks are mounted into it, not given separate drive letters.
  • FHS gives major directories a purpose: /etc config, /var/log logs, /tmp ephemeral, /home personal files.
  • Absolute paths are unambiguous everywhere; relative paths depend on the working directory — use absolute paths in scripts.
FHS conventions feel like trivia until you're debugging something and instinctively know where to look first — that instinct is what this lesson builds.
