Final Review — Cheat Sheet

This is a reference page, not a new lesson — no new material, no quiz. It pulls together the commands and traps from Lessons 1–25 into one place to skim before the exam.

Command cheat sheet

Filesystem, permissions & storage

  • find / ls -la / pwd — navigate and locate files (Lesson 2)
  • chmod 755 file / chmod u+x file — numeric vs. symbolic permissions (Lesson 3)
  • chown user:group file — change ownership (Lesson 3)
  • lsblk / df -h / cat /etc/fstab — disks, usage, and permanent mounts (Lesson 9)

Users, processes & jobs

  • id / groups / sudo vs su — identity and privilege escalation (Lesson 4)
  • visudo — the only safe way to edit /etc/sudoers (Lesson 4)
  • ps aux / kill -15 (SIGTERM, ask nicely) / kill -9 (SIGKILL, last resort) (Lesson 5)
  • nohup cmd & / disown / tmux — survive logout (Lesson 6)

Services & systemd

  • systemctl start/enable --now <service> — start now vs. survive reboot are separate settings (Lesson 7)
  • journalctl -u <service> --since "1 hour ago" -p err — the standard narrowed log query (Lesson 19)
  • systemctl --failed / journalctl -b / journalctl -b -1 — after a failed boot (Lesson 25)

Package management

  • apt install / dpkg -L (Debian family) vs. dnf install / rpm -ql (RHEL family) (Lesson 8)

Networking & SSH

  • ip addr / ip route / ss -tulnp / dig — diagnose outward, in order (Lesson 10)
  • ssh-keygen → ssh-copy-id → key-only login; never copy the private key (Lesson 11)
  • PasswordAuthentication no / PermitRootLogin no in sshd_config — production hardening (Lesson 11)

Bash & text processing

  • set -euo pipefail — near-mandatory for any real script (Lesson 13)
  • Always quote variables: "$var", never bare $var (Lesson 13)
  • grep | sort | uniq -c | sort -rn — the standard "count and rank" pipeline (Lesson 14)

Kernel, memory & CPU

  • /proc and /sys — live kernel state, the same source top/ps/free read from (Lesson 15)
  • free -h — watch "available," not "free"; low free + high cache is normal (Lesson 16)
  • nproc before judging any load average number — it's meaningless without core count (Lesson 17)

Performance, security & containers

  • vmstat 1 5 — first command for any "it's slow," before top (Lesson 18)
  • getenforce / aa-status — check before assuming a permissions bug (Lesson 20)
  • Namespaces isolate what a process sees; cgroups limit what it can use — the two mechanisms behind every container (Lesson 21)

Debugging

  • strace -p <pid> — every system call a running process makes (Lesson 23)
  • lsof -i :<port> — what's already using a port (Lesson 23)

Top 7 exam traps

  1. A manual mount disappears on reboot — only /etc/fstab makes it permanent. See Lesson 9.
  2. systemctl start and systemctl enable are independent — running now doesn't mean it survives a reboot, and vice versa. See Lesson 7.
  3. Cron jobs run with a minimal environment — no normal $PATH, so scripts that work by hand fail silently under cron unless they use full command paths. See Lesson 22.
  4. "Permission denied" with correct Unix permissions almost always means SELinux or AppArmor is the real blocker, a separate layer on top of normal permissions. See Lesson 20.
  5. A low "free" memory number with a high "buff/cache" number is healthy, not a leak — watch "available" instead. See Lesson 16.
  6. Bash doesn't stop on a failed command by default — set -euo pipefail is what makes a script fail fast instead of continuing with bad state. See Lesson 13.
  7. Restarting a failed service before reading its logs destroys the evidence needed to find the real cause. See Lesson 24.
