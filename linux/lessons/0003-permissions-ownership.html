Permissions & Ownership

Every file has an owner (a user) and a group, plus three permission sets — one for the owner, one for the group, one for everyone else. Each set has three bits: read, write, execute.

Simple example: ls -l on a file shows -rwxr-xr--. Read it in three chunks of three: owner (rwx = read+write+execute), group (r-x = read+execute, no write), others (r-- = read only).

The permission bits, and the two ways to set them

BitFile meaningDirectory meaning
r (read)Can view contentsCan list files
w (write)Can modify contentsCan create/delete files inside
x (execute)Can run it as a programCan cd into it

You set permissions two ways:

  • Symbolic: chmod u+x file (add execute for the user/owner), chmod g-w file (remove write for the group)
  • Numeric (octal): each set is one digit, 0-7, adding r=4, w=2, x=1. chmod 755 file = owner 7 (rwx), group 5 (r-x), others 5 (r-x)

Ownership is separate from permissions: chown newuser file changes the owner, chgrp newgroup file changes the group, chown newuser:newgroup file does both at once.

Try it — before looking below

Q1. What does chmod 644 set?

Owner: read+write (6=4+2). Group: read only (4). Others: read only (4). The standard permission for a regular file that isn't meant to be executed.

Now do it yourself

touch myfile.txt
ls -l myfile.txt          # see the default permissions
chmod 640 myfile.txt      # owner rw-, group r--, others ---
ls -l myfile.txt          # confirm the change
chmod u+x myfile.txt      # add execute for the owner only
ls -l myfile.txt

Source

chmod(1) man page — the official reference for every permission mode.

Recap
  • Every file has an owner, a group, and three permission sets (owner/group/others), each with read/write/execute.
  • Numeric mode: r=4, w=2, x=1, added per set — 755 = rwxr-xr-x.
  • chmod changes permissions; chown/chgrp change ownership — two separate commands for two separate things.
Confused by a specific permission error? Paste the exact ls -l output and ask — permission bugs are almost always readable once you know how to parse that line.
