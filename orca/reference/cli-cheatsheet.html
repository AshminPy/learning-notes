Orca: many agents, many tasks — Reference

CLI cheat sheet

Flags checked with orca <command> --help on Orca 1.4.224 (2026-10-12). Add --json when a script or agent reads the output. Always confirm with --help after an Orca update.

Is Orca up?

orca status                 # app + runtime ready?
orca repo list              # repos Orca knows
orca worktree ps            # one-line summary of every worktree (live terminals, unread)

Start agents in parallel (fan-out)

# new independent worktree + agent + task, in one command
orca worktree create --repo path:/abs/repo --name <task> --no-parent \
  --agent claude --prompt "<task brief>" [--activate]

# fresh agent in the CURRENT worktree (no new checkout)
orca terminal create --worktree active --command "codex"

Watch and steer

orca terminal list --worktree <selector>
orca terminal read --terminal <handle>
orca terminal wait --terminal <handle> --for tui-idle --timeout-ms 60000
orca terminal send --terminal <handle> --text "<message>" --enter
orca worktree set --worktree active --comment "fix done; running tests"

A timed-out terminal wait still prints a result. Check satisfied: true before you send — text typed into a TUI that is still starting is lost.

Clean up

orca worktree rm --worktree name:<task> [--force]   # --force: folder only, never forces branch deletion

Learn more from the installed version

orca skills get orca-cli
orca skills get orchestration
