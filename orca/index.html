Orca: Many Agents, Many Tasks

Stop working one task at a time with one agent. This course teaches you to run several AI coding agents in parallel with Orca — each in its own git worktree — and still keep control of quality. It starts with two agents side by side, then racing agents on one hard task, then reviewing and shipping their work, then driving it all from the CLI, and ends with orchestration, where one agent directs others. Every lesson has a short quiz and a hands-on task on your own repo.
