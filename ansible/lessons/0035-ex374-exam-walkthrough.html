You've now got 34 lessons of hands-on Ansible behind you — playbooks, roles, dynamic inventory, vault, and a capstone that tied all of it together. This lesson teaches nothing new. The 9 official exam domains — reconfirmed

Re-checked directly against Red Hat's own EX374 exam page (fetched 2026-07-31), the same source cited in Lesson 1 and MISSION.md: Red Hat Certified Specialist in Developing Automation with Ansible Automation Platform (EX374). Confirmed directly from the page: it's a "hands-on, practical exam" that "requires you to undertake real-world tasks" — not multiple choice — consisting of "a single section lasting four hours," based on Red Hat Ansible Automation Platform 2.5. The 9 domains, exactly as Red Hat names them:

  1. Understand and use Git
  2. Manage inventory variables
  3. Manage task execution
  4. Transform data with filters and plugins
  5. Delegate tasks
  6. Manage content collections
  7. Manage execution environments
  8. Manage inventories and credentials
  9. Manage automation controller

Unlike some multiple-choice certifications, Red Hat does not publish a percentage weighting per domain for this exam — confirmed by its absence from the official page. Treat all 9 as equally exam-relevant rather than trying to guess which ones matter more.

Self-check: can you do this without looking?

Go domain by domain. Answer out loud or on paper before opening the linked lesson. Hesitating is useful information, not failure — it tells you exactly where to spend the next practice session.

1. Understand and use Git

  • Can you clone a repo, create a branch, commit a change, and push it, from memory, with no lookup?

2. Manage inventory variables

  • Can you explain the difference between group_vars/all.yml and a host's own host_vars file, and which one wins? → Lesson 21
  • Can you name where -e/extra-vars sits in the precedence order relative to role defaults and inventory group_vars? → Lesson 22

3. Manage task execution

  • Can you run only the tasks tagged config in a large playbook, from memory? → Lesson 24
  • Can you explain what --check --diff will and won't catch before a real run? → Lesson 29

4. Transform data with filters and plugins

  • Can you write a Jinja2 filter chain from memory, e.g. defaulting an undefined variable and uppercasing it? → Lesson 13
  • Have you actually written a working lookup() call yourself, even once, outside this course? (If not — that's this domain's real gap, flagged above.)

5. Delegate tasks

  • Can you explain the difference between delegate_to and run_once, and when you'd combine them? → Lesson 25

6. Manage content collections

  • Can you install a pinned collection version from a requirements.yml, from memory? → Lesson 19
  • Have you ever run ansible-galaxy collection init yourself? (If not — this domain's real gap, flagged above.)

7. Manage execution environments

  • Can you explain what an execution environment actually packages, and why it's more than "just a container"? → Lesson 30

8. Manage inventories and credentials

  • Can you explain the real difference between a Vault-encrypted variable and an Automation Controller machine credential? → Lesson 26, Lesson 31

9. Manage automation controller

  • Can you describe how a job template ties an inventory, a credential, and a playbook together? → Lesson 31

Exam format reminders

Confirmed directly against Red Hat's own pages, dated 2026-07-31:

  • Hands-on, not multiple choice. The official page's own words: "This hands-on, practical exam requires you to undertake real-world tasks."
  • Timed. "This exam consists of a single section lasting four hours."
  • Version-specific. "This exam is based on Red Hat Ansible Automation Platform 2.5."
  • Closed workspace. Red Hat's remote-exam FAQ states candidates must "avoid having any materials or content related to the course or exam subject in your workspace" — Red Hat does not publish an explicit blanket "no internet access" statement on the pages checked for this lesson, so don't assume open-book access to external docs either way; prepare to work from memory and hands-on muscle memory, not a browser tab.

Try it — before looking below

Q1. You have a plaintext vars/db.yml file with a real password in it, already sitting on disk. Write the exact command that encrypts it in place, without retyping its contents.

ansible-vault encrypt vars/db.yml — from Lesson 26. It encrypts the existing file's contents in place; no need to recreate it with ansible-vault create or retype anything.

Q2. A 40-task playbook has one task tagged restart_only. During the exam you need to run just that one task, fast, without touching anything else. What exact flag do you add to ansible-playbook?

--tags restart_only — from Lesson 24. This runs only tasks (or blocks/roles/plays) carrying that tag, skipping the other 39 tasks entirely, instead of running the whole playbook and hoping the change lands correctly.
