The Gemini Enterprise App: The Consumer Front Door

Lesson 1 drew a line between the Gemini Enterprise Agent Platform (the developer floor) and Gemini Enterprise, the app (the business-user floor). This lesson is the only stop this course makes on that upper floor — every lesson after this one returns to the platform side, so get a complete picture of it now while it's the whole focus.

Mental model: think of the Gemini Enterprise app as a company intranet built around agents instead of documents. A normal intranet gives you search and folders; this one gives you Agent Designer (build an agent without code), Agent Gallery (install one someone else already built and validated), Inbox (watch and steer the ones currently running), Projects (a shared, context-scoped workspace), and Canvas (co-edit real documents with an agent). That predicts something concrete: a non-developer on your team can go from "I have a repetitive process" to "I have a working agent doing it," entirely inside this one app, without writing a line of code or touching ADK.

Agent Designer: no-code, natural language

Per Google's own announcement, Agent Designer lets users "create agents to automate complex, multi-system processes with simple, natural language." It's the app's answer to "I need an agent" for someone who has never written code — you describe the process, Agent Designer builds the agent. Lesson 11 (Phase C) goes deep on how; this lesson only needs you to know it exists and where it sits.

Related to it, but a separate feature: Skills, per Google's own description, let you "formalize a specific workflow — like applying brand guidelines or formatting a report — and save it as a reusable action for your whole team," so an agent uses the right skill automatically instead of being re-explained the same context every time.

Agent Gallery: agents you don't have to build

Not every agent needs building from scratch. Google states: "we are launching Agent Marketplace integrated into the Agent Gallery, giving your users the ability to easily browse and request specialized third-party agents from partners like Accenture, Oracle, and ServiceNow" — a catalog of validated, partner-built agents, distinct from Agent Designer's build-your-own path.

Inbox: where you watch and steer running agents

Agents, especially long-running ones, need somewhere for a human to check in. Per Google: "Inbox is a central command location to monitor, guide, and securely manage all of your agent activity. Notifications are intuitively categorized into actionable groups like 'Needs your input,' 'Errors,' and 'Completed,' giving you a clear, consolidated view of ongoing agent progress."

Projects: a scoped, shared workspace

Projects is described as "a dynamic, highly collaborative workspace where human experts and agents actively co-create side-by-side. By unifying your shared context across various sources — Google Workspace, Microsoft OneDrive, team chats, and more — the agent acts as a dedicated expert on your specific initiative." The key word is unifying — an agent inside a Project only knows what that Project has connected, not your whole company's data by default.

Canvas: co-editing real documents

Canvas is the app's editor: "Canvas allows teams to create and edit Docs or Slides in a single pane, with rich formatting and live co-editing," and Google has added "Microsoft 365 interoperability, allowing you to export the docs and slides you've created within Canvas into common Microsoft Office formats."

Try it

Q1. Your team wants to use a pre-built ServiceNow integration agent someone else already validated, not build one from scratch. Which feature do they open: Agent Designer or Agent Gallery?

Agent Gallery — the catalog of validated, partner-built agents. Agent Designer is for creating a new agent from scratch with natural language, not installing an existing one.

Now, before revealing: a long-running agent has been executing a multi-step workflow and just hit an error needing your decision. Which feature surfaces that to you — Projects, or Inbox?

Reveal the answer

Inbox. It's the unified hub for monitoring and managing running agents, categorizing exactly this kind of event under "Needs your input" or "Errors." Projects is a workspace, not a monitoring feed.

Common mistake: assuming Agent Designer and Agent Studio are the same thing because both have "Agent" and "Studio/Designer" in the name. Agent Designer is the no-code tool inside the Gemini Enterprise app, covered in this lesson. Agent Studio is a separate, code-adjacent environment on the platform side, covered in Lesson 12 alongside raw ADK — the same no-code-versus-code split as the app-versus-platform line from Lesson 1, just one level deeper.

A controlled failure

You open Canvas expecting a blank document editor, and ask an agent to pull last quarter's numbers straight into it — but you haven't set this up inside a Project connected to that data.

Predict first: does Canvas give the agent access to your company's data automatically, or does something else need to happen first? Observe: Canvas is described purely as an interactive editor for Docs and Slides — it doesn't itself grant an agent access to company data. Projects is what "unifies shared context across sources" and scopes what an agent knows. Without a Project connecting the right data source first, Canvas gives you a capable co-editor with no numbers to pull — the trap is assuming any Gemini Enterprise agent automatically knows your company's data everywhere, when Projects is specifically the feature that grants that context.

Production note: Agent Gallery agents come from named third parties (Accenture, Oracle, and ServiceNow, per Google's own launch announcement). Treat installing one the same way you'd treat approving any third-party integration — check what data access and scopes it requests before rolling it out company-wide. That's the same governance instinct Phase F formalizes on the platform side with Agent Identity, Agent Gateway, and Model Armor; Agent Gallery is where that instinct first matters for a non-developer clicking "install."

Recap
  • The Gemini Enterprise app has five core features: Agent Designer (no-code build), Agent Gallery (install a validated third-party agent), Inbox (monitor running agents), Projects (a context-scoped shared workspace), and Canvas (co-edit Docs/Slides).
  • Projects, not Canvas, is what scopes an agent's access to your company's data — Canvas is just the editor.
  • Agent Designer (no-code, in the app) and Agent Studio (code-adjacent, on the platform — Lesson 12) are different tools, not two names for the same thing.
