Keyboard Workflow — Lesson 10 of 24

Karabiner-Elements and the Hyper key

Lesson 1 gave AeroSpace a set of bindings. Lesson 2 gave Raycast its own. Every app on your Mac already ships with its own native shortcuts too — and the more bindings you add, the sooner two of them collide. This lesson installs one small tool that ends that problem for good: a single key, held down, that sends a modifier combination nothing else on your Mac already claims.

Mental model: Karabiner-Elements sits between your physical keyboard and macOS itself, rewriting key events before any app — including macOS — ever sees them. It's not a Settings panel tweak; it's a translator intercepting the signal at the hardware level.

What Karabiner actually does

macOS's own Keyboard settings let you remap a handful of keys, one-to-one. Karabiner-Elements goes further with two layers:

  • Simple Modifications — one key becomes a different single key. Built into the app's UI, no config file needed.
  • Complex Modifications — a key (or key + modifiers) becomes any output: a different key, a modifier combination, even a shell command — optionally conditioned on which app is frontmost. These are JSON rules, either written by hand or imported from a rule.

A complex modification rule is a from (what you press) mapped to a to (what gets sent instead). Per Karabiner's own JSON reference, a to entry can pair a key_code with a modifiers array:

{
  "key_code": "a",
  "modifiers": ["command", "control", "option", "shift"]
}

That's the building block the Hyper key is made from.

The Hyper key: one key, four modifiers

Caps Lock sits in one of the best spots on the keyboard — home row, easy pinky reach — and almost nobody uses it for its actual job. The community-standard fix: remap it to send Command+Control+Option+Shift together, all at once. No macOS shortcut, and no app's native shortcut, uses that exact four-key combination — which means every binding you build on top of it is guaranteed collision-free.

{
  "title": "Caps Lock -> Hyper Key",
  "rules": [
    {
      "description": "Caps Lock alone sends Escape; held with another key, sends Hyper",
      "manipulators": [
        {
          "type": "basic",
          "from": {
            "key_code": "caps_lock",
            "modifiers": { "optional": ["any"] }
          },
          "to": [
            {
              "key_code": "left_shift",
              "modifiers": ["left_command", "left_control", "left_option"]
            }
          ],
          "to_if_alone": [
            { "key_code": "escape" }
          ]
        }
      ]
    }
  ]
}

to_if_alone is what makes this practical: tap Caps Lock by itself and you get Escape (handy in its own right); hold it with another key and that key gets sent with all four Hyper modifiers attached.

Why this closes the loop with Lessons 1 and 2

Once Caps Lock is your Hyper key, you have a whole new binding layer to hand to AeroSpace and Raycast — separate from AeroSpace's own ctrl-alt bindings and Raycast's own hotkeys, and guaranteed not to fight either of them. A generic example: bind Hyper+1 in AeroSpace to jump to workspace 1, and Hyper+Space as an alternate Raycast trigger. Nothing else on the system will ever intercept either combination first.

Security note: the first time you launch Karabiner-Elements, macOS will prompt you to grant Input Monitoring and Accessibility permissions in System Settings → Privacy & Security, and to approve its driver/system extension under Login Items & Extensions. That's expected — Karabiner needs Accessibility to capture keyboard events and detect the frontmost app, which is also what lets it switch rules per app. Without it granted, your rules will simply do nothing; it isn't a sign anything is wrong.

Try it

Install Karabiner-Elements (tying back to Lesson 9): brew install --cask karabiner-elements. Open it, grant the permissions it asks for, then go to the Complex Modifications tab and add a Caps Lock → Hyper rule — either paste the JSON above via "Add rule," or use "Add predefined rule" → "Import more rules from the internet" and search for one. Test it: hold Caps Lock and press a letter inside a normal text field. Nothing should happen — which is exactly the point, since no app claims that combination yet.

Quiz

Q1. Why remap Caps Lock specifically to be the Hyper key?

A. It's an easy-reach key that almost nobody uses for its real job — a wasted key turned into a whole new layer.

Q2. What makes Cmd+Ctrl+Opt+Shift together a good modifier choice?

A. All four modifiers held at once is a combination nothing else claims — that's the entire point, not speed or requirement.

Q3. What two macOS permissions does Karabiner-Elements need to function?

A. Accessibility lets it detect the frontmost app and capture events; Input Monitoring is largely superseded by Accessibility in current versions.

Q4. In the JSON rule above, what does to_if_alone control?

A. It's the tap-vs-hold split: alone gets Escape, held-with-another-key gets the Hyper combination via to.

Q5. Why does the Hyper key connect back to Lessons 1 and 2?

A. It adds a collision-free layer on top of both tools' existing bindings — it doesn't replace or reconfigure either one.

Recap
  • Karabiner-Elements intercepts keyboard events below the app layer — Simple Modifications for 1-to-1 swaps, Complex Modifications (JSON) for anything richer.
  • The Hyper key: remap Caps Lock to send Cmd+Ctrl+Opt+Shift together, with to_if_alone keeping a plain tap as Escape.
  • Requires Input Monitoring + Accessibility permissions and an approved driver extension — a real, expected prompt, not a red flag.
  • This gives AeroSpace (Lesson 1) and Raycast (Lesson 2) a brand-new binding layer that can never collide with any app's native shortcuts.

Try solo: pick one AeroSpace binding and one Raycast hotkey you use often, and add a Hyper+ alternate for each — confirm neither triggers anything else first.

Rule not firing, or permissions dialog not appearing? Tell your teacher exactly what you see in Karabiner's Complex Modifications tab and the EventViewer — macOS permission dialogs are easy to dismiss by accident.
