Atuin and zoxide, from first principles

Both tools are already wired into your .zshrc — eval "$(atuin init zsh)" and eval "$(zoxide init zsh)". This lesson covers what each one actually replaces: Atuin takes over Ctrl-R (history search), zoxide takes over cd (directory jumping).

Atuin: your history becomes a database

The default shell keeps history as a plain text file — one line per command, searched top to bottom. Atuin replaces that file with a SQLite database and records extra context per command: exit code, working directory, hostname, duration, timestamp.

A plain .zsh_history is a pile of receipts in a shoebox — you can only flip through them in order. Atuin is the same receipts filed in a database you can query: "every terraform plan that succeeded, run from this folder, this week."

Press Ctrl-R (or the up arrow, on an empty line) and Atuin opens a full-screen search UI instead of the old single-line reverse-search.

KeyWhat it does
Ctrl-R / ↑Open the search UI
EnterRun the selected command immediately
TabInsert the command into your shell line for editing first
Ctrl-R (pressed again, inside the UI)Cycle filter mode: all hosts → this machine → this directory → this session
Esc / Ctrl-C / Ctrl-D / Ctrl-GCancel and return to the shell, no command run

Every command is also queryable from the command line without opening the UI: atuin search --cwd . --exit 0 cargo finds commands starting with "cargo" that succeeded, run in the current directory. Duration is recorded and shown per result, though it's a display field, not a separate filter flag like --exit or --cwd.

The one-time import

Atuin only knows about commands run after it was installed. If you've been using the terminal for years without it, your old shell history file has thousands of lines Atuin has never seen. One command fixes that, once:

atuin import auto

It detects your current shell and imports its existing history file. Run it once, right after install — your old history file keeps working normally either way, Atuin just reads a copy of it into its own database.

Atuin can also sync history across machines, end-to-end encrypted before it leaves your laptop — hosted by the Atuin team, or self-hosted if you'd rather run the sync server yourself. Optional, not required for search to work locally.

zoxide: cd that remembers where you've been

Every cd you already run gets tracked. zoxide ranks directories by frecency — how often and how recently you visited each one — so a short, partial name jumps you to the right place without a full path.

cd needs the exact path every time. z just needs enough of the name to be unambiguous, ranked by your own habits — z proj beats typing cd ~/projects, once you've actually visited it before.
CommandWhat it does
z fooJump to the highest-ranked directory matching "foo"
z foo barJump to a directory matching both "foo" and "bar"
z ..Up one directory, same as plain cd ..
z -Back to the previous directory
zi fooInteractive fuzzy picker over matches (needs fzf v0.51.0+)
zoxide query fooPrint the matched path without jumping there — for scripts

One catch worth remembering: zoxide only ranks directories you've actually cd'd into before. It's not a filesystem search — it's a memory of your own habits, so a brand-new folder won't be reachable by z until you've visited it at least once.

Try it

Pick a directory you've cd'd into before this week. Jump to it with z and a partial name instead of typing the full path. Then press Ctrl-R, search for something you ran recently, and press Ctrl-R again until the filter mode reads "this directory only."

Quiz

Q1. What does Atuin replace the default Ctrl-R behavior with?

A. Atuin swaps the default single-line reverse-search for a full-screen search UI reading from a SQLite database of your command history.

Q2. What one-time command pulls your existing shell history into Atuin?

A. atuin import auto detects your shell and imports its existing history file — a one-time step, not something that happens automatically.

Q3. zoxide's frecency ranking combines what two signals?

A. Frecency = frequency + recency — directories you visit often, or visited lately, rank higher for a short partial-name match.

Q4. What underlying tool does zi's interactive picker require?

A. zi hands matches to fzf for fuzzy selection — the documented minimum is fzf v0.51.0.

Q5. Inside Atuin's search UI, what does pressing Ctrl-R repeatedly do?

A. Each extra press cycles the filter mode: all hosts, this machine, this directory, this session — no separate key needed.

Recap
  • Atuin replaces Ctrl-R with a full-screen search over a SQLite history database — Enter runs, Tab edits, repeated Ctrl-R cycles the filter (host/machine/directory/session).
  • atuin import auto is a one-time step to pull in history from before you installed it.
  • zoxide replaces cd with z, ranked by frecency (frequency + recency) — zi adds an interactive picker via fzf.
  • Both only know what you've actually done — Atuin needs the import, zoxide needs you to have visited a directory at least once.

Try solo: for one week, catch yourself typing a full cd path or scrolling history with the arrow keys — replace it with z or Ctrl-R instead, every time.
