Keyboard Workflow — Lesson 2 of 8

Raycast, beyond app launching

You use Raycast like Spotlight: hotkey, type an app name, Enter. That's maybe 10% of it. This lesson covers the rest: built-in commands, the Extension Store, and skipping typing entirely for the things you do dozens of times a day.

The one idea that explains everything else

Spotlight, Dock, and Finder all work the same way: browse, then click — scan icons, find the thing, act. Raycast flips this: type your intent, act immediately. You never scan — you state what you want and the first result is almost always right.

Default hotkey: ⌥ Space (Raycast Settings → General). You can rebind to ⌘ Space to fully take over Spotlight's shortcut.

Built-in commands beyond app launching

Clipboard History — the biggest zero-mouse win. Keeps a searchable list of everything you've copied: text, images, files, links, colors. ⌘P filters by type, ⌘K opens the action panel, Enter pastes. Free tier keeps 1 month; Pro extends that.

Window management — Raycast has its own tiling commands (halves, quarters, maximize). Since AeroSpace already tiles, disable these — two tiling systems fighting over one window is worse than either alone. Raycast Settings → Extensions → Window Management, toggle each command off.

Calculator — type math into Root Search. Handles unit conversions (10ft in m), time zones (5pm ldn in sf), dates, percentages, currency. Enter copies the answer.

Quicklinks — turn a URL, file, folder, or app deeplink into a named shortcut. Create via Create Quicklink; can autofill from your active browser tab.

Snippets — stored text inserted by search or a keyword trigger (like ;;sig) that expands anywhere on your Mac.

Try it

Copy three different things in a row. Open Raycast (⌥ Space) → Clipboard History → Enter. Arrow down to the third item (the first thing you copied), Enter to paste it. No mouse, nothing lost.

The Extension Store

Built-ins are the floor. Extensions are community/vendor mini-apps that install in one click and behave like built-in commands. For your stack:

  • Amazon AWS (Falcon, ~9,700 installs) — EC2, S3, ECR, DynamoDB, CloudWatch, Secrets Manager, Lambda logs, across profiles, no browser needed.
  • Kubernetes (justin0u0, ~960 installs) — browse resources, switch context/namespace. Logs, port-forwarding, delete are still planned, not shipped — check the Store page before relying on it.
  • Terraform Doc (ShoppingJaws, ~590 installs) — jumps to Terraform resource docs.
  • Google Cloud Platform Search (klaa97) — searches GCP products and your projects, opens the right console page.

Hotkeys: skip the search step

Root Search → ⌘, → Configure Command → Set Hotkey
(or: Raycast Settings → Shortcuts → Record Hotkey)

A hotkey fires a command globally, even with Raycast closed. An alias just ranks a command higher inside Root Search — it still needs the search step. Good hotkey candidates: Clipboard History, your most-used AWS/Kubernetes lookup.

Quiz

Q1. What best describes Raycast's core model, vs Spotlight/Dock/Finder?

A. Raycast is state-intent-and-act, not browse-then-click. The others describe browse-then-click or invented mechanics.

Q2. How long does Raycast's free tier keep clipboard history?

A. One month free. B/C/D are all Pro-only options.

Q3. Why disable Raycast's window-management commands if you use AeroSpace?

A. Two systems owning the same window's size/position will fight. It's free (not C), and AeroSpace runs fine beside Raycast otherwise (not D).

Q4. What does Raycast's built-in Calculator support beyond basic arithmetic?

A. Time zone math, dates, currency (incl. crypto), and unit conversion, typed straight into Root Search.

Q5. What's the real difference between a Quicklink and a Snippet?

A. Quicklink navigates to a saved location; Snippet inserts stored text. Both are free and work with files too.

Recap
  • Raycast's model: type intent, act — not browse-then-click.
  • Clipboard History is the biggest zero-mouse win; disable Raycast's window management since AeroSpace already owns tiling.
  • The Extension Store turns Raycast into a control surface for AWS, Kubernetes, Terraform, GCP; hotkeys beat aliases for your most-used commands.

Try solo: install the AWS or Kubernetes extension, find one command you'd use often, bind it to its own hotkey.
