Keyboard Workflow — Lesson 2 of 4

Raycast, beyond app launching

You installed Raycast after a video, and you use it the same way you used Spotlight: hit a hotkey, type an app name, hit Enter. That's maybe 10% of what it does. This lesson covers the other 90% — the built-in commands that replace Finder and the Dock too, the Extension Store (the actual power-user unlock), and how to skip typing entirely for the handful of things you do dozens of times a day.

The one idea that explains everything else

Spotlight, the Dock, and Finder all share the same mental model: browse, then click. You look at icons, scan a folder, find the thing, then act on it. Raycast replaces all three with a different model: type your intent, act immediately. You never scan — you state what you want ("open X", "convert Y", "paste Z") and the first result is almost always correct.

Default hotkey to open Raycast is ⌥ Space (Option-Space) — set in Raycast Settings → General. You can also rebind it to ⌘ Space, which fully takes over the shortcut Spotlight normally owns, so there's no muscle-memory conflict between the two.

Built-in commands beyond app launching

These ship with Raycast — no extension install needed.

Clipboard History. This is the single biggest "zero mouse" win. Normally, copy-paste chains break the moment you need something you copied two steps ago — you have to go find it again with the mouse. Clipboard History keeps a searchable list of everything you've copied: text, images, files, links, colors. Open it from Root Search, use ⌘P to filter by type, ⌘K for an action panel with more options (like "Paste as plain text"), and Enter to paste the highlighted entry straight into whatever field you were in. Free tier keeps 1 month of history; Pro extends that to 6 months, a year, or unlimited.

Window management. Raycast ships its own window commands — halves, quarters, sixths, maximize, center, move-to-next-display. Since AeroSpace already owns tiling on your machine, don't run both — two tiling systems fighting over the same window is worse than either alone. Go to Raycast Settings → Extensions → Window Management and disable the individual commands (every command has its own enable/disable toggle) — keep Raycast for launching and clipboard, let AeroSpace keep the tree.

Calculator. Type math straight into Root Search — no separate app. It handles more than arithmetic: unit conversions (10ft in m), time zones (5pm ldn in sf), dates (days until 31 Mar), percentages, and currency (including crypto). Enter copies the answer to your clipboard.

Quicklinks. Turn a URL, file path, folder, or app deeplink into a named, searchable shortcut — e.g. type "prod dashboard" instead of navigating to a bookmark. Create one with the Create Quicklink command; Raycast can autofill from your active browser tab.

Snippets. Stored text you insert with a few keystrokes — either by searching for it manually, or by typing a keyword trigger (like ;;sig) that auto-expands anywhere on your Mac, not just inside Raycast.

Try it — on your real desktop, right now

Copy three different things in a row — a sentence from a doc, a filename, a short line from your terminal. Now open Raycast (⌥ Space), type "Clipboard History", press Enter. Use the down arrow to move to the third item from the top (the first thing you copied), press Enter to paste it into a blank field. You never touched the mouse and you never lost something two copies back — that's the whole point of this command.

The Extension Store — the real power-user unlock

Built-in commands are the floor. The Extension Store is where Raycast stops being "a faster Spotlight" and starts being a control surface for everything you actually do all day. Extensions are community or vendor-published mini-apps that install with one click and then behave exactly like built-in commands — same Root Search, same keyboard-only flow. Searching the live Store for your stack (cloud/DevOps: GCP, AWS, Kubernetes, Terraform) turned up:

  • Amazon AWS (by Falcon, ~9,700 installs) — search and open EC2 instances, S3 buckets, ECR repos, DynamoDB tables, CloudWatch log groups, Secrets Manager and Parameter Store entries, Lambda logs, across multiple AWS profiles, without opening the console in a browser.
  • Kubernetes (by justin0u0, ~960 installs) — browse cluster resources and switch contexts/namespaces from Raycast. Worth flagging honestly: pod logs, port-forwarding, and delete actions are listed as planned, not shipped yet — check the Store page before relying on it for anything beyond browsing.
  • Terraform Doc (by ShoppingJaws, ~590 installs) — jumps straight to Terraform resource documentation instead of a browser search.

Also worth a look since you're GCP-heavy: Google Cloud Platform Search (by klaa97) — searches GCP products and your own projects, and opens straight to the right console page or docs.

Hotkey customization: skip the search step entirely

Typing "Clipboard History" and pressing Enter is already fast. But for the 2-3 things you do dozens of times a day, even that's one step too many. Raycast lets you bind a command straight to its own global hotkey, bypassing Root Search completely:

Select the command in Root Search → ⌘, → Configure Command → Set Hotkey
(or: Raycast Settings → Shortcuts → find the command → Record Hotkey)

This is different from an alias (a short keyword that just ranks a command higher when Root Search is already open). A hotkey works globally, even with Raycast closed — press the combo, the command fires immediately. Good candidates for you: Clipboard History, and whichever AWS/Kubernetes lookup command you'd otherwise type out every time.

Quiz

Q1. What best describes Raycast's core mental model, compared to Spotlight, Dock, and Finder?

A. Raycast's whole design is stating intent and acting, not browsing — you never scan icons the way Dock/Finder require. B and D describe browse-then-click, the exact model Raycast replaces. C is wrong on mechanics: Raycast uses one hotkey, not two, and it launches commands, not drag operations.

Q2. By default, how long does Raycast's free tier keep clipboard history?

A. Free tier retention is capped at one month. B, C, and D are all Pro-tier options (6 months, 1 year, unlimited) — none of them are what you get without upgrading.

Q3. Inside Clipboard History, which key pastes the highlighted entry into your active field?

A. Return is the paste action. B and C are real shortcuts in the same command, but they do different jobs — filter by type, and open the action panel — neither pastes anything. D just closes the window with nothing pasted.

Q4. Why should you disable Raycast's window-management commands if you already use AeroSpace?

A. Two systems trying to own the same window's position and size will fight each other — that's the actual reason to turn one off. B has it backwards; you're keeping AeroSpace, not replacing it. C is false — window management is a free built-in feature. D is false too — AeroSpace and Raycast run fine side by side; it's specifically the overlapping window-sizing commands that conflict, not the apps themselves.

Q5. What does Raycast's built-in Calculator support, beyond basic arithmetic?

A. The calculator handles time zone math, date arithmetic, currency (including crypto), and unit conversion, all typed straight into Root Search. B, C, and D each describe a calculator far more limited than what's actually built in.

Q6. What is the real difference between a Quicklink and a Snippet in Raycast?

A. A Quicklink navigates you to a saved location (URL, file, folder, deeplink); a Snippet inserts stored text into whatever you're typing. B swaps the two definitions. C is wrong — Quicklinks work for file paths and folders too, not just websites. D is wrong — both are free, no Pro account needed.

Q7. How do you skip the type-to-search step and jump straight to one command?

A. A hotkey bound directly to a command fires it instantly, with Root Search never opening at all — that's the actual mechanism. B reintroduces the Dock, which is the exact browse-then-click habit this lesson is replacing. C abandons Raycast entirely. D would remove other useful commands without giving the one you want its own trigger.

Q8. Which extension from the live Raycast Store search lets you browse EC2, S3, and CloudWatch resources?

A. The Amazon AWS extension (by Falcon) covers EC2, S3, ECR, DynamoDB, CloudWatch, Secrets Manager, and more. B covers Kubernetes clusters, not AWS resources. C only opens Terraform documentation pages. D searches Google Cloud, a different provider entirely.

Recap
  • Raycast's model is type intent, act — not browse-then-click like Spotlight, Dock, or Finder.
  • Clipboard History is the biggest zero-mouse win — search and paste anything you copied, not just the last thing.
  • Window management ships built in, but disable it command-by-command since AeroSpace already owns tiling — don't run two systems fighting for the same window.
  • Calculator, Quicklinks, Snippets cover math/conversions, saved locations, and reusable text — all built in, no install needed.
  • The Extension Store is where Raycast becomes a control surface for your actual stack — AWS, Kubernetes, Terraform, and GCP extensions all exist and install with one click.
  • Hotkeys (global, work anywhere) beat aliases (only rank higher inside Root Search) for the handful of commands you run dozens of times a day.

Try solo: install the AWS or Kubernetes extension (whichever matches something you touch today), find one command inside it you'd use often, and bind it to its own hotkey via ⌘, → Configure Command → Set Hotkey.
