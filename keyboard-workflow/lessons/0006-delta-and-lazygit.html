Keyboard Workflow — Lesson 6 of 8

delta and lazygit

Stock git diff is hard to read — red and green text, no structure, everything in one column. Stock git also makes you type a full command for every single action: stage this file, commit, push, switch branch. This lesson fixes both problems: delta makes diffs readable, lazygit makes the rest of git driveable from the keyboard.

Simple example: think of delta as new glasses for git — it doesn't change what git did, just how clearly you see it. Think of lazygit as a cockpit — one screen where every git action is one keypress away, instead of one typed command away.

delta: a pager, not a replacement

delta sits between git and your terminal. It reads the raw output of git diff, git show, and git log -p, and redraws it before you see it: side-by-side view, syntax highlighting per language, and line-level highlighting that shows exactly which words changed inside a line — not just which lines.

Important: installing delta with Homebrew does not turn it on. Git has no idea delta exists until you tell git to use it as the pager. Skipping this step is the #1 reason people think "delta doesn't do anything."

The wiring is one git config line:

git config --global core.pager delta

That's the one that matters. Two more are worth adding at the same time:

git config --global interactive.diffFilter 'delta --color-only'
git config --global delta.navigate true

interactive.diffFilter makes git add -p (picking hunks to stage) use delta's coloring too. delta.navigate true turns on n / N to jump between file sections in a large diff — no more scrolling past a file you don't care about.

Try it

Run git config --global core.pager delta now. Then cd into any git repo with history and run git log -p — you should see side-by-side, syntax-highlighted diffs instead of plain red/green text. If it looks unchanged, the config line didn't apply — check git config --global core.pager prints delta.

lazygit: git without typing git commands

lazygit is a full-screen terminal app. Run lazygit in any git repo, and it opens a dashboard: unstaged files, staged files, branches, commits, and stash — all visible at once, all navigable with arrow keys. You stage, commit, branch, and push by pressing single keys instead of typing full commands.

KeyWhat it does
spaceStage (or unstage) the selected file
cCommit the currently staged changes
pPull from the remote
PPush to the remote (capital — different key from pull)

Everything stays visible while you work — no re-running git status to check what's staged, because the staged/unstaged split is just always on screen.

Try it

Change a file in any git repo. Run lazygit. Arrow down to the changed file in the Files panel and press space to stage it — using only the keyboard, no mouse. Press q to quit when done (don't commit or push yet if you're just practicing).

Quiz

Q1. What must happen after brew install git-delta for delta to actually appear in your diffs?

A. Installing the binary just puts it on disk. Git only calls it once core.pager is set to delta.

Q2. Which command wires delta in as git's default pager?

A. That's the documented config line — it sets git's core.pager value to delta globally.

Q3. What's the main visual improvement delta gives over stock git diff?

A. Delta adds side-by-side layout, per-language syntax color, and highlights exactly which words changed inside a line — stock git only colors whole lines red or green.

Q4. How do you open lazygit for the repo you're currently in?

A. lazygit is a standalone terminal program — running lazygit in a repo's directory opens its dashboard for that repo.

Q5. In lazygit's Files panel, which key stages the currently selected file?

A. space is the documented stage/unstage toggle in lazygit's Files panel.

Recap
  • delta is a pager for diff/show/log -p — side-by-side, syntax-highlighted, word-level.
  • It does nothing until wired in: git config --global core.pager delta.
  • lazygit is a full-screen git dashboard — run lazygit in any repo.
  • Core keys: space stage, c commit, p pull, P push.

Try solo: set delta as your pager on this machine today, then do your next real commit entirely inside lazygit — no typed git commands.
