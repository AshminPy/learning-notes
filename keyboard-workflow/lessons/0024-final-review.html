Top facts to remember

  • The Hyper key frees a whole shortcut layer. Once Caps Lock sends Cmd+Ctrl+Opt+Shift (Lesson 10), every AeroSpace and Raycast binding built on it can never collide with an app's native shortcuts.
  • Dotfiles-as-code is what makes the rest of this course reproducible. A Brewfile (Lesson 9) plus a tracked dotfiles repo (Lesson 11) turn "I set this up once, a year ago, I don't remember how" into a single restore command.
  • direnv is what actually prevents "wrong account" mistakes (Lesson 20) — not a habit you have to remember, but an automatic load/unload tied to the directory itself.
  • A YubiKey-backed SSH key never leaves the hardware (Lesson 14). The touch (and PIN) proves physical presence — the one thing remote malware can't forge.
  • Verify identity before you act, every time, on every platform: aws sts get-caller-identity (18), gcloud auth list (19), git config user.email (16), kubectl config current-context (21). Different clouds, same discipline.
  • Measure before you optimize. Lesson 23's zprof habit generalizes: don't guess what's slow or wrong, get a number or a real check first — the same instinct behind ssh -v (13) and aws sts get-caller-identity (18).
  • Automate the second repetition, not the first. A Warp Workflow (3), an Atuin search (4), or a stern command (22) all replace "type the long version again" with "search or alias it once."
