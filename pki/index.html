PKI Engineer — Zero to Hero

You've joined a company as its new PKI Engineer. This course trains you from your first day — starting at zero cryptography knowledge — through certificates, TLS, public and private PKI, Microsoft AD CS, certificate lifecycle automation, Kubernetes and cloud PKI, private key security, troubleshooting, and enterprise PKI architecture, ending with a capstone: modernizing a company's entire broken certificate program. No single certification anchors this course — it's built for real production PKI engineering, covering everything from your first CSR to designing a CA hierarchy for 20,000 employees.

This is an independent study resource, not affiliated with, endorsed by, or sponsored by any certificate authority, browser vendor, or standards body. PKI moves fast — certificate validity periods, CA/Browser Forum requirements, and post-quantum standards all change over time. Always check current official documentation (CA/Browser Forum, NIST, IETF RFCs, Mozilla/Chrome/Apple root programs, Microsoft docs) before relying on exact specifics.

Progress levels

Levels 1-3 (Beginner through Administrator) are the core path to "Job-Ready PKI Engineer." Levels 4-5 add enterprise-scale engineering and architecture. Stages P (Governance) and X (Commercial CA Operations) are an optional Architect track — most PKI Engineer roles don't require public-CA-operator depth, so they're not required for the core milestone.

  • Level 1 — PKI Beginner: understands keys, certificates, encryption, signing, trust
  • Level 2 — PKI Technician: can create CSRs, inspect certificates, install certificates, build chains, troubleshoot basic problems
  • Level 3 — PKI Administrator: can operate AD CS, manage templates, issuance, renewal, revocation
  • Level 4 — PKI Engineer: can automate lifecycle, manage enterprise PKI, troubleshoot complex failures, secure keys, integrate HSMs
  • Level 5 — PKI Architect: can design CA hierarchies, enterprise PKI, machine identity, disaster recovery, governance, and cryptographic migrations
